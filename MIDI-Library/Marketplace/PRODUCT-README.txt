WHAT'S INSIDE
  Chords/                 All chord qualities in all 12 keys
  Progressions/           Chord progressions by scale and by genre
  Basslines/              Genre-accurate bass patterns, all 12 keys
  Melodies/               Melodies across minor/pentatonic/Dorian/harmonic
  Arps/                   Arpeggio patterns
  Drums/By-Genre/         GM drum-map grooves (full / minimal / tops)
  Arrangement-Templates/  One-file starters: Chords+Bass+Arp+Drums on
                          separate tracks, ready to build on
  MANIFEST.csv            Searchable index (key, scale, genre, BPM, bars)

GENRES: Deep / Future / Progressive / Tech House, Techno, Melodic Techno,
        Trance, Hardstyle, Hardcore/Gabber, Dubstep, Future Bass, Lo-fi.

HOW TO USE
  • Every .mid carries its own tempo — drag it onto an instrument/MIDI
    track in any DAW (Ableton, FL Studio, Logic, Bitwig, Cubase, Studio
    One, Reaper) and it plays at the correct BPM.
  • Drum files use the General MIDI map (36=kick, 38=snare, 39=clap,
    42/46=hats). Drop them onto any drum rack.
  • Arrangement-Templates are multi-track: each part lands on its own
    track so you can assign a different sound to each.

NAMING: <Key>m_<what>_<detail>.mid  (sharps spelled "s": As=A#, Cs=C#)
