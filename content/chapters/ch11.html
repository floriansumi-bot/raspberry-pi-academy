Python is the perfect first programming language — it reads almost like plain English, runs instantly, and comes pre-installed on every Raspberry Pi. In this chapter you will write your very first lines of code, understand what they do, build up to a complete mini-game, and learn how to add extra Python tools the safe, Bookworm-correct way.

What is programming?

A computer does exactly what you tell it — nothing more, nothing less. A program is simply a list of very precise instructions written in a language the computer can follow. Every instruction is carried out in order, from top to bottom, unless you deliberately tell the computer to jump around.

Imagine a recipe for making toast:

  1. Put bread in toaster.
  2. Press the lever down.
  3. Wait until the bread pops up.
  4. Spread butter on the toast.
  5. Serve.

A Python program works exactly like that recipe. Each line is one instruction. The computer reads line 1, carries it out, then reads line 2, carries it out, and so on. If you leave out a step, or write one in the wrong order, you get the wrong result — just like forgetting to put bread in the toaster first.

In plain words: Programming means writing a list of instructions in a special language that a computer can understand and carry out automatically.

Why Python?

There are dozens of programming languages. Python is chosen as the default on the Raspberry Pi for good reasons:

  • Its instructions look like short English sentences, so beginners can guess what code means even before they have learned it properly.
  • You can test a single line of code immediately without building an entire project.
  • There is an enormous library of ready-made tools for everything from controlling GPIO pins to analysing spreadsheets.
  • It is one of the most-used languages in science, education, automation, and professional software development worldwide.
  • The Raspberry Pi Foundation has built a beginner-friendly editor called Thonny that makes writing and running Python programs as easy as using a word processor.

Two ways to run Python code

On your Pi you have two main routes to writing and running Python. Both are useful and you will use both regularly.

Method 1 — Thonny (the easy visual editor)

Thonny is a purpose-built Python editor designed for people who have never programmed before. It has a big text area where you type your code, a green Run button you click, and a panel at the bottom (called the Shell) that shows you what happens when the program runs. You can also type single lines directly into the Shell to test them instantly.

To open Thonny, click the raspberry icon in the top-left corner of the desktop, go to Programming, and click Thonny. You can also type thonny in a terminal and press Enter.

Method 2 — the terminal (python3 myfile.py)

Once you have saved a Python file you can also run it from the terminal without opening Thonny at all. This is quicker when you already know the code is ready.

Open a terminal window (the black icon on the taskbar, or from the menu under Accessories → Terminal). If your file is called hello.py and you saved it in your home folder, type:

python3 hello.py

python3 — launches the Python 3 interpreter (the program that reads and runs Python code). On Raspberry Pi OS always write python3, not just python, to make sure you get the modern version.

hello.py — the name of the file to run. Python files always end in .py.

Tip: Use Thonny while you are learning — it highlights errors, shows line numbers, and lets you run code one step at a time. Switch to the terminal later when you are comfortable.

Method 3 — the interactive Python shell (REPL)

There is a third option that is perfect for quick experiments: the Python REPL (Read-Evaluate-Print Loop). You launch it by typing python3 in a terminal and pressing Enter, with no filename. You then type one line of Python at a time and see the result instantly.

In plain words: REPL stands for Read-Evaluate-Print Loop. Python reads your line, evaluates it (runs it), prints the result, and then waits for the next line. It is like a calculator that understands Python.
python3

python3 (with no filename after it) — starts the interactive Python shell. Your prompt changes to >>>, which means Python is waiting for your input.

Once you see the >>> prompt, try these:

>>> 2 + 2
4
>>> print("Hello from the REPL!")
Hello from the REPL!
>>> name = "Raspberry Pi"
>>> name
'Raspberry Pi'
>>> exit()

>>> 2 + 2 — you type the expression after the >>> prompt; Python immediately prints the answer 4 on the next line.

print("Hello from the REPL!") — works exactly as in a script.

name = "Raspberry Pi" — creates a variable. Variables created in the REPL persist for the whole session.

name — typing a variable name on its own (without print) shows its value. This only works in the REPL, not in a saved script.

exit() — closes the Python shell and returns you to the normal terminal prompt.

Tip: You can also use the REPL from inside Thonny — it is the Shell panel at the bottom. Click in it and type away.

Your first Python building blocks

The rest of this chapter introduces the core ideas of Python one at a time. Each section has a short runnable example. Open Thonny, type each example in the editor panel, and press the green Run button to see what happens. Do not just read — actually type the code. Your fingers will remember it.

print() — showing things on screen

print() is the simplest instruction in Python. It tells the computer to display whatever is inside the brackets on screen.

print("Hello, world!")
print("I am learning Python.")
print(42)
print(3.14)

print("Hello, world!") — displays the words Hello, world! followed by a new line. The text must be inside quote marks so Python knows it is a piece of text, not a command.

print("I am learning Python.") — displays a second sentence. Each print() call starts on a new line automatically.

print(42) — prints a whole number. Numbers do not need quote marks.

print(3.14) — prints a decimal number (called a float in Python).

In plain words: A function in Python is a named action you can trigger by writing its name followed by brackets. print() is one of Python's built-in functions — it performs the action of displaying something on screen.

Variables — giving things a name

A variable is like a labelled box. You put a piece of information inside, give the box a name, and then use that name whenever you need the information later. You can change what is inside the box at any time.

age = 25
name = "Florian"
price = 4.99

print(name)
print(age)
print(price)

age = 25 — creates a variable called age and stores the number 25 in it. The = sign means "store this value in this box", not "equals" in the mathematical sense.

name = "Florian" — stores the text Florian in a variable called name. Text values are always wrapped in quote marks.

price = 4.99 — stores a decimal number.

print(name) — displays whatever is stored in the variable name (in this case, Florian).

print(age) and print(price) — display the contents of those variables in turn.

Tip: Variable names should be short and descriptive. Use lowercase letters and underscores for spaces (for example player_score, not PlayerScore or playerscore). Python is case-sensitive: Name and name are two different variables.

Strings and numbers

In plain words: In programming, a piece of text is called a string because it is a "string of characters". Numbers come in two flavours: whole numbers (integers, like 7 or −3) and decimal numbers (floats, like 3.14).

You can join strings together with + and do maths with numbers:

first = "Raspberry"
second = " Pi"
full = first + second
print(full)

a = 10
b = 3
print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a ** b)

first + second — glues two strings together end-to-end. Notice the space at the start of " Pi" so the result reads Raspberry Pi, not RaspberryPi.

a + b — adds 10 and 3, giving 13.

a - b — subtracts, giving 7.

a * b — multiplies (* is the multiply sign in Python), giving 30.

a / b — divides, giving approximately 3.333…

a ** b — raises to a power: 10³ = 1000. Two asterisks mean "to the power of".

To mix a number and a string in one print(), you can either use a comma (which adds a space automatically) or an f-string (a modern, cleaner method):

score = 95
print("Your score is", score)
print(f"Your score is {score} out of 100.")

print("Your score is", score) — the comma tells print() to display both items with a space between them. This is the quick-and-easy method.

f"Your score is {score} out of 100." — an f-string. The letter f before the opening quote mark tells Python to look for variable names inside curly braces {} and replace them with the variable's value. This is the cleanest way to build sentences that include variable values, and is the recommended modern approach.

input() — asking the user a question

input() pauses the program and waits for the user to type something and press Enter. Whatever the user types is returned as a string.

name = input("What is your name? ")
print(f"Hello, {name}! Welcome to Python.")

input("What is your name? ") — displays the prompt text, then waits. When the user presses Enter, everything they typed is stored in name as a string.

print(f"Hello, {name}! ...") — greets the user by name using an f-string.

Careful: input() always gives you a string, even if the user types a number. If you want to do maths with it, you must convert it first: age = int(input("How old are you? ")). The int() function converts a string like "25" into the number 25. If the user types something that is not a number (for example "hello"), Python will crash with a ValueError. You will learn how to handle that safely in the error-handling section below.

if / elif / else — making decisions

Programs need to make decisions: "if this is true, do that; otherwise, do something else." Python uses the keywords if, elif (short for "else if"), and else.

In plain words: Indentation means the spaces or tabs at the start of a line. Python uses indentation to show which lines belong inside an if block. Press the Tab key once to indent — Thonny does this automatically when you press Enter after a colon. Indentation is one of the most important rules in Python — get it wrong and the program will either crash or behave unexpectedly.
temperature = int(input("Enter today's temperature in C: "))

if temperature >= 25:
    print("It's a warm day -- perfect for a picnic!")
elif temperature >= 10:
    print("Mild weather. Maybe bring a light jacket.")
else:
    print("It's cold! Wrap up warm.")

int(input(...)) — gets a number from the user. The outer int() converts the typed text into a whole number so we can compare it mathematically.

if temperature >= 25: — checks whether the temperature is 25 or above. The colon at the end is required; Thonny will automatically indent the next line for you.

print(...) — this line is indented (four spaces or one Tab), which tells Python it belongs inside the if block and only runs if the condition is true.

elif temperature >= 10: — only checked if the first condition was false. If the temperature is between 10 and 24, this branch runs.

else: — runs if none of the above conditions were true (temperature below 10). No condition is needed — it is the "everything else" catch-all.

Symbol Meaning Example
==equal toscore == 100
!=not equal tocolour != "red"
>greater thanage > 18
<less thanprice < 10
>=greater than or equal toscore >= 50
<=less than or equal toweight <= 100
Note: Notice that "equal to" uses two equals signs (==), not one. A single = means "store a value in a variable". Using = when you mean == is one of the most common beginner mistakes in Python — if your if statement behaves unexpectedly, check this first.

for loops — repeating a fixed number of times

A loop lets you repeat a block of instructions without writing it out multiple times. A for loop repeats a set number of times, or once for each item in a collection.

for i in range(5):
    print(f"This is repetition number {i + 1}")

print("Loop finished!")

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(f"I like {fruit}.")

for i in range(5): — repeats the indented block 5 times. The variable i takes the values 0, 1, 2, 3, 4 in turn (Python counts from zero by default).

print(f"... {i + 1}") — we add 1 to i so the displayed count starts at 1 instead of 0, which looks more natural to a human reader.

print("Loop finished!") — this line is not indented, so it only runs once, after the loop has completed all five repetitions.

fruits = [...] — a list of three strings (more on lists shortly).

for fruit in fruits: — repeats the block once for each item in the list. On each pass, fruit holds the current item (apple, then banana, then cherry).

while loops — repeating until a condition changes

A while loop keeps repeating for as long as a condition is true. It is useful when you do not know in advance how many repetitions you need.

count = 1
while count <= 5:
    print(f"Count is {count}")
    count = count + 1

print("Done!")

count = 1 — starts a counter at 1, before the loop begins.

while count <= 5: — keeps looping as long as count is 5 or less. The condition is checked before every repetition.

count = count + 1 — increases the counter by 1 each time around. Without this line the counter would never change, the condition would always be true, and the loop would run forever (an infinite loop). You can also write this more concisely as count += 1, which means exactly the same thing.

print("Done!") — runs only after the loop has finished, because it is not indented inside the loop.

Careful: If your program seems to freeze and keeps printing the same thing, you probably have an infinite loop. Press Ctrl + C in the Shell (or click the red Stop button in Thonny) to force it to stop.

Lists — storing multiple items together

A list is a single variable that holds several values in a fixed order. You create one with square brackets [] and separate items with commas.

colours = ["red", "green", "blue", "yellow"]

print(colours[0])
print(colours[2])
print(len(colours))

colours.append("purple")
print(colours)

colours.remove("green")
print(colours)

colours[0] — accesses the first item. Python counts positions starting from zero, so [0] = first, [1] = second, [2] = third, and so on. This is called zero-based indexing.

colours[2] — the third item, which is blue.

len(colours) — returns how many items are in the list. len is short for "length". The result here is 4.

colours.append("purple") — adds purple to the end of the list. The dot before append means "call this action on this particular list".

colours.remove("green") — removes the first occurrence of green from the list. If the item is not in the list, Python will raise a ValueError.

Dictionaries — storing information with labels

A dictionary is like a list, but instead of numbered positions you access each item by a meaningful key. Think of a real dictionary: you look up a word (the key) to find its meaning (the value).

In plain words: A dictionary in Python stores pairs of information: a key and a value. You look up a value by its key, just like looking up a word in a printed dictionary. Dictionaries use curly braces {}.
person = {
    "name": "Alice",
    "age": 30,
    "city": "London"
}

print(person["name"])
print(person["age"])

person["age"] = 31
print(person["age"])

person["country"] = "UK"
print(person)

person = {"name": "Alice", ...} — creates a dictionary with three entries. Each entry is a key-value pair separated by a colon. Keys are usually strings (in quotes); values can be any type.

person["name"] — retrieves the value stored under the key "name", which is Alice. You use square brackets with the key name, not a number.

person["age"] = 31 — updates the value of an existing key. The old value (30) is replaced with 31.

person["country"] = "UK" — adds a brand-new key-value pair to the dictionary. Dictionaries grow automatically as you add keys.

print(person) — prints the entire dictionary, showing all keys and their current values.

Functions — packaging instructions you will reuse

A function is a named block of code that you write once and can call (run) as many times as you like, anywhere in your program. You define one with the keyword def.

def greet(person_name):
    print(f"Hello, {person_name}!")
    print("Great to have you here.")

greet("Alice")
greet("Bob")
greet("everyone")

def greet(person_name): — defines a new function called greet. Inside the brackets is a parameter — a temporary variable that will hold whatever value you pass in when you call the function. The colon and indentation work the same way as with if.

The two indented print lines — the body of the function. They only run when the function is called, not when Python first reads the definition.

greet("Alice") — calls the function and passes Alice as the value of person_name. The body runs with person_name equal to Alice.

The function is called three times with different names, without repeating the code three times — this is the core benefit of functions.

Functions can also send a result back using return:

def add(x, y):
    result = x + y
    return result

total = add(7, 3)
print(f"7 plus 3 equals {total}")

def add(x, y): — defines a function that accepts two values, named x and y.

result = x + y — calculates the sum and stores it temporarily.

return result — sends the calculated value back to wherever the function was called from. Once Python hits return, the function stops and hands the value back.

total = add(7, 3) — calls the function with 7 and 3; the returned value (10) is stored in total.

Comments — notes inside your code

A comment is a line (or part of a line) that Python completely ignores. It is there for you — to explain what the code is doing, leave reminders, or temporarily disable a line.

# This whole line is a comment -- Python skips it entirely.

age = 30  # The user's age in years

# TODO: add a check that age is a positive number
print(age)

# — any text after a hash symbol on a line is a comment. Python ignores everything from the # to the end of that line. You can put a comment on its own line, or at the end of a line of code.

# TODO: ... — a common convention. Writing TODO in a comment is a reminder to yourself of something you still need to add or fix.

Comments are extremely valuable — even experienced programmers write them constantly. Get into the habit of explaining why you wrote something, not just what it does.

Handling errors gracefully — try / except

Sometimes your program will encounter a situation it cannot handle — for example, the user types "hello" when you expected a number. Without protection, Python crashes with an error message. The try / except block lets your program catch the problem and respond politely instead.

In plain words: try / except is Python's way of saying "try this; if something goes wrong, do this instead". It stops a crash from reaching the user.
try:
    raw = input("Enter a number: ")
    number = int(raw)
    print(f"Double your number is {number * 2}")
except ValueError:
    print("That doesn't look like a number. Please try again.")

try: — starts the protected block. Python attempts every line inside this block.

number = int(raw) — converts the input to a whole number. If the user typed something that is not a number, this line would normally crash the program.

except ValueError: — if a ValueError occurs anywhere inside the try block (which is what int() raises when given non-numeric text), Python jumps here instead of crashing.

print("That doesn't look like a number...") — the friendly message shown to the user instead of a scary error. The program continues normally after this.

Tip: You do not need to wrap every line in a try / except. Use it wherever you take input from the user or read from a file — those are the places where unexpected things are most likely to happen.

Putting it all together — a number-guessing game

Now let us build a complete, working program that uses everything you have just learned. The game picks a secret number between 1 and 20, then keeps asking the player to guess it, giving hints ("too high" or "too low") until the player gets it right. It also handles the case where the user types something that is not a number, without crashing.

In Thonny, open a new file (File → New), type the code below exactly as written, then save it as guess_game.py (File → Save As…) and press the green Run button.

import random

# Pick a secret number between 1 and 20
secret = random.randint(1, 20)
attempts = 0

print("Welcome to the Number Guessing Game!")
print("I have picked a number between 1 and 20.")
print("Can you guess it?\n")

def check_guess(guess, secret):
    if guess < secret:
        return "Too low! Try higher."
    elif guess > secret:
        return "Too high! Try lower."
    else:
        return "correct"

# Keep looping until the player guesses correctly
guessed = False
while not guessed:
    raw = input("Your guess: ")

    try:
        guess = int(raw)
    except ValueError:
        print("Please enter a whole number.")
        continue

    attempts = attempts + 1
    hint = check_guess(guess, secret)

    if hint == "correct":
        print(f"\nYou got it! The number was {secret}.")
        print(f"It took you {attempts} attempt(s). Well done!")
        guessed = True
    else:
        print(hint)

print("\nThanks for playing!")

import random — loads Python's built-in random module, which contains tools for generating random numbers. The import keyword loads a module (a collection of ready-made functions) so you can use them.

secret = random.randint(1, 20) — picks a random whole number between 1 and 20 (both 1 and 20 are possible) and stores it in secret. This is different every time the program runs.

attempts = 0 — a counter that starts at zero and increases each time the player makes a valid guess.

print("...\n") — the \n inside a string prints a blank line, making the output easier to read. \n is called a newline character — it is an invisible instruction to move down one line.

def check_guess(guess, secret): — defines a function that compares the player's guess to the secret number and returns a hint string, or the word "correct" if the guess is right.

guessed = False — a boolean variable (its value is either True or False) that tracks whether the player has won yet.

while not guessed: — keeps looping for as long as guessed is still False. As soon as guessed becomes True, the loop stops after the current pass.

try: guess = int(raw) — safely converts the typed text to a number. If the user typed something like "abc", the except ValueError catches it instead of crashing.

continue — inside a loop, continue skips the rest of the current pass and goes straight back to the top of the loop (the while condition check). This restarts the loop without incrementing the attempts counter for an invalid entry.

attempts = attempts + 1 — increments the attempt counter. We only reach this line if the input was a valid number.

hint = check_guess(guess, secret) — calls our function and stores the returned hint string.

if hint == "correct": — if the function returned the exact string "correct", the player has won. Note the double equals sign for comparison.

guessed = True — sets the flag so the while loop will stop after this pass.

else: print(hint) — if the guess was wrong, display the "too low" or "too high" message and loop around again.

print("\nThanks for playing!") — runs once the loop has ended, after the player has guessed correctly.

Tip: Once the game works, try changing 20 to 100 in the randint call to make it harder. Try adding a maximum number of guesses — if the player reaches 7 wrong guesses, print "Game over!" and reveal the secret number. Experimenting like this is the fastest way to learn.

Errors are normal — do not panic

Every programmer, beginner and expert alike, sees error messages constantly. An error message is Python's way of telling you exactly where it got confused. It is helpful, not an accusation.

The three most common error types you will see:

Error type What it means Common cause
SyntaxError Python could not understand the line at all — it is not valid Python Missing colon after if, def, or for; unmatched brackets; wrong quote marks
NameError You used a variable or function name that Python does not know about Typo in the name, or using a variable before creating it
TypeError You tried to do something with the wrong type of value Adding a number and a string without converting one of them first, e.g. "score: " + 5
ValueError The right type, but an impossible value Calling int("hello") — the string is the right type but cannot be converted to a number
IndexError You tried to access a list position that does not exist A list has 3 items but you asked for mylist[5]

Always read the last line of the error message first — it tells you the error type and a short description. The lines above it show the traceback — the chain of code that led to the crash, with the exact line number. In Thonny the offending line is also highlighted in red.

Note: If the error message seems baffling, copy the exact error text and search for it online — you will almost always find a clear explanation on a site called Stack Overflow, or in the Raspberry Pi forums at forums.raspberrypi.com.

Saving and re-running scripts

In Thonny, save your file with Ctrl + S. Choose a meaningful name ending in .py and save it somewhere easy to find, such as a folder called python_projects inside your home directory.

To re-run a saved file from the terminal, navigate to its folder first and then run it:

cd ~/python_projects
python3 guess_game.py

cd ~/python_projects — changes the current directory to your python_projects folder. The tilde (~) is shorthand for your home directory (for example /home/pi on a standard Raspberry Pi OS install). If the folder does not exist yet, create it first with mkdir ~/python_projects.

python3 guess_game.py — runs the file. The terminal prints the output exactly as it would in Thonny's Shell panel.

Tip: Press the Up arrow key in the terminal to recall your previous commands. This saves a lot of retyping when you are testing and re-running a program repeatedly.

Adding extra Python libraries — the Bookworm-correct way

Python's real power comes from its huge collection of libraries (also called packages or modules) — ready-made bundles of code that do specific jobs, from drawing charts to talking to web APIs to controlling the Pi's GPIO pins.

In plain words: A library is a collection of functions someone else has already written and packaged up so you can use them with a single import statement. You do not need to understand how they work internally — you just use them.

On Raspberry Pi OS Bookworm the system Python is externally managed. This means the operating system itself uses and maintains Python, and it protects itself by preventing you from installing packages into it with the plain pip install command. If you try, you will see a message like:

error: externally-managed-environment

This is not a bug — it is a deliberate safety measure introduced in Debian 12 (Bookworm) to stop accidental changes to the system Python from breaking the operating system itself. It means "stop — you need to use one of the safe methods below instead".

You have two safe, recommended approaches.

Approach 1 — install via apt (for common libraries)

For the most popular Python libraries, Raspberry Pi OS provides pre-packaged versions through its built-in package manager apt. This is the simplest method and is fully supported by the system.

sudo apt update
sudo apt install python3-requests
sudo apt install python3-numpy
sudo apt install python3-matplotlib

sudo apt update — refreshes the list of available packages from the internet so you get the latest versions. Always run this first before installing anything.

sudo apt install python3-requests — installs the requests library (used for fetching web pages and data from the internet) in a way that is fully compatible with the system Python. The naming pattern is always python3- followed by the library name.

python3-numpy — installs NumPy, a library for numerical calculations and arrays, widely used in science and data analysis.

python3-matplotlib — installs Matplotlib, which draws charts and graphs.

To find out whether a library is available through apt, search for it:

apt-cache search python3- | grep requests

apt-cache search python3- — lists all Python 3 packages known to apt. The list can be very long.

| grep requests — the vertical bar (pipe) sends that list through the grep filter, which only shows lines containing the word requests. Replace requests with whatever library you are looking for.

Approach 2 — use a virtual environment (for everything else)

If the library you need is not in apt, or you need a newer version than apt provides, use a virtual environment. This is a self-contained, isolated copy of Python that lives in a folder of your choosing. You can install anything into it with pip without touching the system Python at all.

In plain words: A virtual environment is like a separate room for your project's Python setup. Anything you install inside that room stays in that room and cannot affect the rest of the system. You can have as many rooms as you like — one per project.

Here is the full process, step by step:

  1. Create the virtual environment. Choose a folder name — we will use myenv. In a terminal: 
    python3 -m venv myenv

    python3 -m venv myenv — tells Python 3 to run its built-in venv module (-m venv) and create a virtual environment in a new folder called myenv. You only need to do this once per project. The folder contains its own Python interpreter and its own library storage area.

  2. Activate the virtual environment. 
    source myenv/bin/activate

    source myenv/bin/activate — "activates" the virtual environment. Your terminal prompt changes to show (myenv) at the front, reminding you that you are inside the virtual environment. From this point on, python3 and pip refer to the virtual environment's own copies, not the system ones.

    Your prompt now looks something like (myenv) pi@raspberrypi:~ $. That (myenv) prefix confirms the virtual environment is active.

  3. Install any library you like with pip. 
    pip install requests

    pip install requests — installs the requests library into the virtual environment only. No sudo is needed and the system Python is not affected. Replace requests with any library name from the Python Package Index (PyPI), which hosts over half a million Python libraries.

  4. Run your Python script as normal. 
    python3 my_script.py

    While the virtual environment is active, python3 automatically uses the environment's Python and can see all the libraries you installed with pip inside it.

  5. Deactivate when you are finished. 
    deactivate

    deactivate — returns your terminal to normal. The (myenv) prefix disappears. The virtual environment still exists in its folder — you just are not inside it any more. Next time you need it, run source myenv/bin/activate again to re-enter it.

Note: You need to activate the virtual environment again each time you open a new terminal window. If you try to run a script that needs a library and get a ModuleNotFoundError, the most likely cause is that you forgot to activate the environment first — just run source myenv/bin/activate and try again.

Which approach should I use?

Situation Best approach
Common library (requests, numpy, matplotlib, RPi.GPIO, pygame…) sudo apt install python3-<name>
Library not available via apt, or you need the very latest version Create a virtual environment and use pip install inside it

Keep experimenting

The best way to learn programming is to break things on purpose and fix them. Change a number, rename a variable, delete a colon and see what error you get. Every mistake teaches you something a textbook cannot. Python is patient — it will never be upset by your experiments, and the worst that can happen is an error message that points you straight to the problem.

Key terms

  • Program — an ordered list of precise instructions written in a language the computer can follow.
  • Python — a popular, beginner-friendly programming language pre-installed on Raspberry Pi OS.
  • Thonny — the beginner-friendly Python editor included with Raspberry Pi OS.
  • REPL — the interactive Python shell, launched by typing python3 alone in a terminal; lets you run one line at a time and see results instantly.
  • print() — a built-in Python function that displays text or values on screen.
  • Variable — a named container that stores a value in your program; the stored value can change at any time.
  • String — a piece of text in Python, written inside quote marks.
  • Integer — a whole number (no decimal point), such as 7 or −3.
  • Float — a decimal number in Python, such as 3.14.
  • Boolean — a value that is either True or False; used to track yes/no states in a program.
  • f-string — a string prefixed with f that lets you embed variable values directly inside curly braces {}.
  • input() — a built-in function that displays a prompt and waits for the user to type something; always returns a string.
  • if / elif / else — keywords used to make decisions: run different code depending on whether conditions are true or false.
  • Indentation — the spaces or tabs at the start of a line that tell Python which lines belong inside an if, for, while, or def block.
  • Loop — a block of code that repeats. A for loop repeats a fixed number of times; a while loop repeats until a condition becomes false.
  • List — a single variable holding multiple values in order, written with square brackets [].
  • Dictionary — a variable holding key-value pairs, written with curly braces {}; you look up values by their key rather than by position.
  • Function — a named, reusable block of code defined with def; can accept inputs (parameters) and return a result.
  • Comment — a note in code starting with # that Python ignores; written for human readers.
  • try / except — a block that catches errors gracefully so the program can respond politely instead of crashing.
  • Library (module / package) — a bundle of ready-made Python functions you can load with import.
  • pip — the Python package installer, used to download and install libraries from the PyPI repository on the internet.
  • apt — the Raspberry Pi OS package manager; use sudo apt install python3-<name> for system-safe Python library installs.
  • Virtual environment (venv) — a self-contained, isolated Python installation in a folder, created with python3 -m venv, where pip can install freely without affecting the system.
  • Externally managed — the Bookworm protection that prevents pip from installing packages into the system Python directly, guarding against accidental damage to the OS.

Chapter summary

  • A program is a precise, ordered list of instructions; Python reads them from top to bottom.
  • Thonny is the easiest way to write and run Python on the Pi; the terminal command python3 filename.py also works once a file is saved.
  • The Python REPL (launched by typing python3 alone) lets you test single lines instantly without creating a file.
  • print() displays output; input() collects text typed by the user (always returned as a string).
  • Variables store values; strings hold text (in quotes), integers hold whole numbers, floats hold decimals, and booleans hold True or False.
  • F-strings (e.g. f"Hello, {name}!") are the cleanest way to build sentences that include variable values.
  • if / elif / else lets your code make decisions based on conditions; use == (two equals signs) to compare, not =.
  • for loops repeat a fixed number of times; while loops repeat until a condition becomes false.
  • Lists store multiple values in a single variable; dictionaries store key-value pairs for labelled data.
  • Functions defined with def let you name and reuse blocks of code.
  • try / except catches errors gracefully so bad user input does not crash your program.
  • Comments (lines starting with #) explain your code to future readers, including yourself.
  • On Bookworm, install common Python libraries safely with sudo apt install python3-<name>; for anything else, use a virtual environment (python3 -m venv myenv) and then pip install inside it.
  • Errors are normal and helpful — read the last line of the error message and the line number it points to; then fix and try again.
  • The best way to learn is to tinker: change the code, break it deliberately, fix it, and build on it.
