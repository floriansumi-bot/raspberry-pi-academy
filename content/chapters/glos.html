Every technology topic comes with its own vocabulary, and it can feel like everyone else already knows the secret language. This glossary collects every significant term used in this book and explains each one in plain English — no assumed knowledge, no shortcuts. Keep this chapter bookmarked: whenever you encounter an unfamiliar word, flip here first.

How to use this glossary

Entries are sorted alphabetically from A to Z. If you are looking for a specific term, scan the letter headings or use your browser's or PDF viewer's Find function (Ctrl + F, or Cmd + F on a Mac). Where two terms are closely related, cross-references appear in italics.

Note: Some entries contain a short example in square brackets — these examples use the Raspberry Pi OS Bookworm command line. You do not need to type them right now; they are just there to make the definition feel concrete.

A

TermMeaning
Active CoolerA small metal heatsink combined with a tiny fan that clips directly onto the Raspberry Pi 5's main chip. It draws heat away and blows it into the air, stopping the Pi from slowing itself down when it gets warm. Many Raspberry Pi 5 starter kits include one already fitted; the official Active Cooler is an inexpensive add-on otherwise.
ADC (Analogue-to-Digital Converter)A chip that turns a varying voltage (an analogue signal) into numbers a computer can read. The Raspberry Pi has no ADC built in, so to read truly analogue sensors you add one such as the MCP3008, connected over SPI.
AliasA short nickname you create for a longer command. For example, you might create the alias update to stand for sudo apt update && sudo apt upgrade, so you only have to type one word.
AnodeThe positive (+) leg of a diode or LED. On an LED it is the longer leg, and current flows in through it. See also cathode.
API (Application Programming Interface)An agreed set of commands one piece of software offers so other programs can use it. A Flask web app exposes an API — for example a /api/data address that hands back sensor readings.
aptThe main tool for installing, updating, and removing software on Raspberry Pi OS. Its full name is "Advanced Package Tool". You use it by typing sudo apt install <name> in the terminal. Think of it as the Pi's official app store, accessed from the keyboard.
ARMA family of processor designs (short for "Advanced RISC Machine"). The Raspberry Pi 5 uses an ARM-based chip. ARM processors are popular in phones and single-board computers because they are power-efficient. Most software you install on the Pi is compiled specifically for the ARM architecture.
ArgumentExtra information you pass to a command to tell it what to work on. In ls /home/pi, the folder /home/pi is the argument — it tells the ls command which folder to list.
AutostartA setting that makes a program launch automatically when the Pi boots or when a user logs in, without you having to open it manually.

B

TermMeaning
BashThe most common shell (command interpreter) on Linux and Raspberry Pi OS. When you open a terminal and start typing commands, Bash is the program reading your input and running the right programs. The name stands for "Bourne Again Shell".
BluetoothA short-range wireless technology for connecting devices — keyboards, mice, speakers, headphones — without cables. The Raspberry Pi 5 has Bluetooth 5.0 built in, which is reliable up to about 10 metres from the Pi.
BMS (Battery Management System)A small circuit that protects a rechargeable battery from being over-charged, over-discharged, or short-circuited. A salvaged phone cell should always keep its protection board attached.
Boost ConverterA small circuit that raises a lower voltage to a higher one — for example lifting a 3.7 V battery up to the 5 V a Raspberry Pi needs.
Boot / BootingThe process of switching a computer on and loading the operating system until it is ready to use. When you press the Pi's power button, it "boots". The word comes from the old saying "pulling yourself up by your bootstraps".
BootloaderA tiny program that runs before the operating system. On the Raspberry Pi 5 it lives in a chip on the board (the EEPROM). Its job is to find the operating system on the microSD card (or SSD) and hand control over to it.
BookwormThe codename for Debian version 12, which is the foundation of the current Raspberry Pi OS. Software instructions that say "Bookworm" apply to this version. Debian names its releases after characters from the film Toy Story.
BreadboardA rectangular plastic board full of small holes used for building electronic circuits without soldering. Components and wires push into the holes and are held in place by friction, making it easy to experiment and rearrange. Perfect for beginners learning about GPIO.
BuzzerA small component that makes sound. An active buzzer has its own built-in tone and only needs switching on and off; a passive buzzer needs the Pi to supply the pitch, letting it play different musical notes.

C

TermMeaning
CallbackA function you hand to a library to be run later — "when" something happens, such as when_motion. You pass it by name, with no brackets, so it is called back at the right moment rather than straight away.
CathodeThe negative (−) leg of a diode or LED. On an LED it is the shorter leg, beside the flat edge of the casing. See also anode.
Class-D AmplifierA highly efficient kind of audio amplifier used in small modules (such as the MAX98357A) to drive a loudspeaker from a low-power source like the Pi.
CLI (Command-Line Interface)A way of controlling a computer by typing text commands rather than clicking icons. The opposite of a GUI. On the Pi, the CLI is accessed through the terminal. It feels unfamiliar at first but becomes very powerful once you know a handful of commands.
CommandA word (or short phrase) you type in the terminal to make the computer do something. For example, ls lists files, and pwd shows your current location.
Config fileA text file that stores settings for a program. Instead of clicking through menus, you edit the file to change how the program behaves. The most important low-level hardware settings file on the Pi is /boot/firmware/config.txt.
ContainerA lightweight, self-contained package that includes an application and everything it needs to run (libraries, settings), but shares the Pi's operating system kernel. Containers made with Docker are popular for running server software cleanly without cluttering the system.
CPU (Central Processing Unit)The main "brain" of the computer — the chip that carries out instructions. The Raspberry Pi 5's CPU has four cores (Arm Cortex-A76) running at up to 2.4 GHz, meaning it can work on up to four things at the same time and executes billions of steps per second.
cron / crontabA built-in Linux scheduler that runs commands automatically at times you specify — for example, "back up my files every night at 2 am". You set it up by editing a file called a crontab (cron table) with the command crontab -e.
CSV (Comma-Separated Values)A simple text format for tables, where each line is a row and commas separate the columns. Spreadsheets and Python’s csv module both read and write it, which makes it ideal for logging sensor data.
CurrentThe flow of electricity through a circuit, measured in amperes (amps, A) or milliamps (mA). Your Pi 5's power supply provides up to 5 A. GPIO pins can each safely supply only about 8–16 mA, so you usually need a resistor to protect an LED.

D

TermMeaning
DebianA long-established, free Linux operating system maintained by a worldwide community of volunteers. Raspberry Pi OS is built on top of Debian, so it inherits Debian's software tools, package system, and stability. Ubuntu is also based on Debian.
DebounceSmoothing out the tiny, rapid on/off flickers a mechanical switch makes at the instant it is pressed. In gpiozero you set a bounce_time so those false extra presses are ignored.
Desktop EnvironmentThe visual layer on top of Linux that gives you a GUI — windows, icons, a taskbar, and a file manager. Raspberry Pi OS uses a desktop environment called PIXEL (built on LXDE/Openbox). Without it you would only see a text terminal.
DHCP (Dynamic Host Configuration Protocol)A service (usually running on your home router) that automatically gives every device on your network an IP address when it connects. You rarely need to configure this yourself — it just works.
DiodeA component that lets electricity flow one way only. An LED is a diode that also gives off light; fitting one the wrong way round simply means it stays dark.
DirectoryAnother word for folder — a container that holds files and other directories. On Linux, directories are separated by forward slashes: /home/pi/Documents.
DNS (Domain Name System)The internet's address book. When you type a website name (like raspberrypi.com), DNS converts it into a numeric IP address that computers can actually route to. Your router usually handles DNS automatically.
DockerA popular tool for creating, running, and managing containers. With Docker you can install a complex application (like a media server or a home-automation hub) as a single command without worrying about dependencies conflicting with other software on your Pi.
Duty CycleThe proportion of time a rapidly switched signal spends "on" versus "off". By varying it with PWM, the Pi can dim an LED or mix a colour — 100% is full brightness, 0% is off.

E

TermMeaning
E-wasteDiscarded electronics — old phones, toys, printers, routers. Much of it is a free source of parts (LEDs, motors, sensors) for projects, though some items (mains adapters, microwaves, CRT screens) are dangerous to open.
EEPROMA tiny memory chip on the Raspberry Pi 5 board that stores the bootloader firmware. Unlike the microSD card, it keeps its contents even when power is removed. You can update it with sudo rpi-eeprom-update.
EncoderA sensor that reports how far and how fast a motor shaft has turned. LEGO NXT motors have one built in, letting your code measure exact angles and distances. See quadrature encoder.
ESD (Electrostatic Discharge)The tiny spark of static electricity that can jump from your hand to a component and silently damage it. Touch something earthed before handling bare electronics.
EthernetA wired networking standard. You plug a standard RJ45 network cable between your Pi and your router to get a fast, reliable internet connection. The Pi 5 supports Gigabit Ethernet (up to 1,000 Mb/s). Wired is always faster and more reliable than Wi-Fi.
Environment variableA named value stored in the shell's memory that programs can read. For example, the variable HOME stores the path to your home folder. You can view all of them with the env command.
EV3The third-generation LEGO Mindstorms controller and its motors and sensors. Its motors are like the NXT’s but their encoders read cleanly at 3.3 V, making them a little friendlier to wire to a Raspberry Pi.

F

TermMeaning
FileA named collection of data stored on a disk — a document, a photo, a program, or a settings file. On Linux, almost everything is treated as a file, including hardware devices.
File systemThe way files and folders are organised on a storage device. The Pi uses the ext4 file system for its main storage, while other systems use formats such as NTFS (Windows), APFS (macOS), or exFAT. They are like different filing systems — you need the right tools to read each one.
FirewallSoftware (or hardware) that blocks or allows network traffic according to rules. On the Pi, ufw (Uncomplicated Firewall) is the friendliest way to set up a firewall. Think of it as a bouncer for your Pi's network connections.
FirmwareSoftware that is embedded very deeply in hardware — closer to the machine than the operating system. The Pi's bootloader is firmware. Your router, your printer, and even your keyboard all have firmware.
Flag / OptionA short switch you add to a command to change its behaviour. Flags usually start with a hyphen: ls -l adds the -l flag to show a detailed list. Some flags use two hyphens: apt install --yes.
FlaskA small, friendly Python library for building websites and web APIs. A few lines of Flask turn your Pi into a web server you can open from a phone on the same network.
FolderSee Directory. Both words mean the same thing — a container for files. "Folder" is the everyday word; "directory" is the technical one you'll see in Linux documentation.
FunctionIn programming, a named block of code that does one specific job. You define it once and can call it by name as many times as you like. In Python: def greet(): starts a function called greet.

G

TermMeaning
GPIO (General Purpose Input/Output)The row of 40 metal pins on the Raspberry Pi that you can connect to electronic components (LEDs, buttons, sensors, motors). Some pins supply power, some are ground (0 V), and the "general purpose" ones can be set as either inputs or outputs by software. The Pi 5 uses 3.3 V logic — never connect 5 V signals directly to GPIO pins.
gpiozeroThe beginner-friendly Python library for controlling GPIO pins on the Raspberry Pi. It comes pre-installed on Raspberry Pi OS. Instead of thinking in raw voltage levels, you work with simple objects like LED, Button, and Buzzer. It is the recommended library for beginners.
GPU (Graphics Processing Unit)A chip designed to process graphics and video very efficiently. The Pi 5's GPU is a VideoCore VII, built into the same chip as the CPU. It handles what you see on screen and can accelerate video decoding.
GroupA collection of user accounts that share the same permissions. For example, the gpio group allows members to access GPIO pins, and the video group allows access to the camera. Adding your user to a group grants those extra permissions.
GUI (Graphical User Interface)A visual way of using a computer — windows, buttons, icons, and menus you click with a mouse. The opposite of the CLI. Raspberry Pi OS Desktop is a GUI. Most beginners start here before learning the terminal.

H

TermMeaning
H-bridgeAn arrangement of four electronic switches that lets a controller run a motor forwards or backwards and vary its speed. It is the standard way to drive a motor from a Pi, since a GPIO pin cannot do it directly. See motor driver.
HapticsFeedback you feel rather than see or hear — typically a small vibration motor buzzing, as used in phones and game controllers.
HAT (Hardware Attached on Top)An add-on board that plugs onto the Pi's 40-pin GPIO header and sits on top of it. HATs follow a standard that includes an ID chip so the Pi can recognise what is attached. Examples: a HAT with an M.2 slot for an NVMe SSD, a display HAT, or a motor-driver HAT.
HDMI (High-Definition Multimedia Interface)The standard cable for sending video and audio to a TV or monitor. The Raspberry Pi 5 has two micro-HDMI ports — smaller than the full-size HDMI port on most TVs and monitors, so you need an adapter or a micro-HDMI-to-HDMI cable (often included in starter kits).
Home AssistantAn open-source smart-home platform you can run on your Pi. It lets you control smart bulbs, thermostats, door locks, and hundreds of other devices from one dashboard — without sending your data to a third-party cloud.
HostnameA human-friendly name for a device on a network. The Pi's default hostname is raspberrypi. You can reach it from another computer on the same network as raspberrypi.local (using mDNS), which is much easier than remembering an IP address.
HSVA way of describing colour by Hue, Saturation and Value (brightness) rather than red/green/blue. It makes it far easier for code to pick out "all the red things" in a camera image — which is how a robot can track a coloured ball. (In OpenCV, hue runs 0–179.)

I

TermMeaning
I2C (Inter-Integrated Circuit)A simple two-wire communication protocol used to connect sensors, displays, and other small electronic components to the Raspberry Pi via the GPIO header. "I-squared-C" or "I-two-C" is how you say it. You enable I2C in raspi-config under Interface Options.
I2S (Inter-IC Sound)A digital audio connection. The Pi 5 has no headphone socket, so an I2S amplifier such as the MAX98357A is a clean way to add sound.
IDE (Integrated Development Environment)A program that makes writing code easier by combining a text editor, error highlighting, and a way to run your code all in one window. Thonny is the IDE pre-installed on Raspberry Pi OS for Python beginners.
Image (disk image)A single file that is an exact copy of an entire storage device — every file and every piece of system data. When you "flash" Raspberry Pi OS to a microSD card, you are writing a disk image. The file usually ends in .img or .img.xz.
Image (Docker image)In the Docker world, an image is the blueprint for a container — it contains the application and all its dependencies, frozen and ready to run. You download images from Docker Hub and turn them into running containers.
Input (GPIO)When a GPIO pin is set to input mode, the Pi reads the voltage on that pin — HIGH (3.3 V) or LOW (0 V) — to detect whether a button has been pressed, a sensor has triggered, or another signal has arrived. The opposite of Output (GPIO).
IP addressA unique numerical label assigned to every device on a network. Local addresses look like 192.168.1.42. Your router assigns one to your Pi automatically via DHCP. An IP address is like a postal address for network traffic.
IP WebcamAn app that turns a phone or camera into a network camera, streaming video over Wi-Fi to an address other devices — such as your Pi — can read.

J

TermMeaning
JellyfinA free, open-source media server you can run on your Pi. It organises your films, TV shows, and music and lets you stream them to phones, tablets, or smart TVs on your network — similar to a private Netflix.
JSONA common text format for storing and exchanging data. Files end in .json. Many configuration files and APIs use JSON because it is easy for both humans and programs to read.

K

TermMeaning
KernelThe deepest, most fundamental part of the operating system. The kernel talks directly to the hardware — the CPU, RAM, storage, and GPIO pins — and lets other programs use them safely. On the Pi, it is a version of the Linux kernel. You rarely interact with it directly.
KodiA popular open-source media centre application. You can install it on your Pi to turn it into a TV set-top box that plays local video files, streaming services, and live TV. LibreELEC is a minimal operating system built entirely around Kodi.

L

TermMeaning
LED (Light-Emitting Diode)A small electronic component that produces light when current flows through it. LEDs are directional — they only work one way round. The longer leg (anode) connects to the positive side. They are the classic first GPIO project: make one blink with Python.
LibraryA collection of pre-written code that your program can use. Instead of writing code to control a GPIO pin from scratch, you import the gpiozero library and use its ready-made functions. Libraries save enormous amounts of time.
LibreELECA tiny, specialised Linux operating system built solely to run Kodi. It boots straight into Kodi, uses minimal resources, and is designed to be very stable. It is a separate OS from Raspberry Pi OS — you flash it to its own card.
LinuxA free, open-source operating system kernel created by Linus Torvalds in 1991. "Linux" is now used loosely to mean any operating system built on that kernel — including Raspberry Pi OS, Ubuntu, and Debian. It runs most of the world's servers and all Android phones.
Lithium-ion Battery (Li-ion)The rechargeable battery in phones and laptops. Powerful but hazardous: never puncture, bend, or use a swollen one, and always keep its protection board attached.
LLM (Large Language Model)The type of artificial intelligence behind chatbots like ChatGPT and Claude. An LLM is trained on vast amounts of text and learns to predict and generate human-sounding language. You can run small LLMs locally on your Pi using tools like Ollama.
localhostA special name (and the IP address 127.0.0.1) that always refers to the computer you are currently using. If you run a web server on your Pi and open http://localhost in a browser on the same Pi, you see that server's output.

M

TermMeaning
mDNS / .localmDNS (Multicast DNS) is a technology that lets devices on a local network find each other by name without a central DNS server. Your Pi advertises itself as raspberrypi.local so that other computers on the same Wi-Fi can find it by that name instead of its IP address.
microSD cardA tiny flash storage card — about the size of a fingernail — used as the main storage for the Raspberry Pi OS. Many starter kits include one, sometimes with Raspberry Pi OS already installed. The Pi reads it through the microSD slot on the underside of the board.
micro-HDMIA smaller variant of the HDMI connector. The Raspberry Pi 5 has two micro-HDMI ports, allowing it to drive two screens simultaneously at up to 4K 60 fps each. You need a micro-HDMI-to-HDMI cable or adapter to connect to a standard TV or monitor.
MIPIThe family of high-speed connections phones use for their cameras (CSI) and screens (DSI). The connectors and drivers are proprietary, which is why a phone camera or screen cannot simply be plugged into a Pi.
MJPEG (Motion JPEG)A simple video format that sends a stream of separate JPEG images. It is an easy way to show a live camera feed on a web page served from your Pi.
Motor DriverA board (built around an H-bridge, such as the DRV8833 or L298N) that takes low-power signals from the Pi and switches the higher current a motor needs.
MultimeterA handheld tester for electronics. It measures voltage, resistance and continuity, and has a diode setting for checking LED polarity — invaluable for testing salvaged parts.

N

TermMeaning
NextcloudA free, open-source file-sync and collaboration platform you can self-host on your Pi. It works like a private Dropbox or Google Drive — you store and share files on your own hardware rather than a company's servers.
NVMe (Non-Volatile Memory Express)A fast type of SSD that connects via a PCIe slot. An NVMe drive in an M.2 form factor, attached to your Pi 5 via a HAT, can be five to ten times faster than a microSD card and is far more reliable for constant read/write workloads.

O

TermMeaning
OllamaA free, open-source tool that makes it easy to download and run LLMs (AI language models) on your own computer — including the Raspberry Pi 5. With one command you can pull a model and chat with it entirely offline.
Open sourceSoftware whose source code (the human-readable instructions that make it work) is freely available for anyone to read, use, modify, and share. Raspberry Pi OS, Linux, Python, LibreOffice, and VLC are all open source. It is the opposite of proprietary software like Microsoft Windows.
OpenCVA popular free library for working with images and video in Python — reading a camera, finding shapes and colours, and feeding pictures to AI models.
Operating system (OS)The fundamental software that manages all the hardware and lets you run applications. Windows 11 is an operating system. So is Raspberry Pi OS. The OS sits between the hardware and your apps, handling memory, files, networking, and security so apps don't have to.
Output (GPIO)When a GPIO pin is set to output mode, the Pi controls its voltage level — pulling it HIGH (3.3 V) or LOW (0 V) — to switch something on or off, such as an LED or a relay. The opposite of Input (GPIO).

P

TermMeaning
PackageA bundle of software — the program itself plus any support files — packaged in a standard format so apt can install, update, or remove it cleanly. Every piece of software you install via sudo apt install is a package.
Package managerA tool that handles installing, updating, and removing software automatically, including all the extra pieces a program depends on. On Raspberry Pi OS the package manager is apt. It saves you from manually hunting down and installing software.
PathThe full address of a file or folder on the file system, written as a series of directory names separated by slashes. /home/pi/Documents/myfile.txt is an absolute path (starts from the very top). Documents/myfile.txt is a relative path (starts from where you are now).
PCIe (PCI Express)A high-speed hardware interface used to connect expansion cards to a computer's main board. The Raspberry Pi 5 has a PCIe 2.0 x1 connector that you can use (via an M.2 HAT) to add a fast NVMe SSD.
PermissionsRules that control who can read, write, or execute each file or folder. Every file on Linux has permissions for the owning user, the owning group, and everyone else. The command ls -l shows them as a string like -rw-r--r--.
Pi-holeA DNS-based ad blocker you can run on your Pi. It acts as the DNS server for your whole home network, intercepting requests to known ad-serving domains and blocking them before they reach any device. Works on every phone, tablet, and computer in your home without installing anything on them.
PIDA control recipe — Proportional, Integral, Derivative — that steers a robot smoothly toward a target by reacting to the size of its error, how long it has persisted, and how fast it is changing. The proportional part alone already gives gentle line-following.
PinOne individual metal connector on the GPIO header. The Pi 5 has 40 pins. Each has a specific role: power supply (3.3 V or 5 V), ground (0 V), or a programmable GPIO pin. Always check a pinout diagram before connecting anything.
pipThe standard Python package installer. You use it to add Python libraries not included with Python itself. On Raspberry Pi OS Bookworm, you should use pip inside a virtual environment or install system packages via apt instead of running pip directly into the system Python, which is marked as "externally managed".
PIR (Passive Infrared) SensorA motion detector that senses the warmth of a moving person or animal. The common HC-SR501 module sends out a clean 3.3 V signal, so its output connects straight to a GPIO pin with no voltage divider.
Port (network)A numbered "door" on a device's network connection. A single IP address can receive many different types of traffic at once by using different ports. Web traffic uses port 80 (or 443 for secure HTTPS), SSH uses port 22, and so on.
PWM (Pulse Width Modulation)A technique for simulating a variable voltage on a digital output pin by switching it on and off very rapidly. By changing the ratio of on-time to off-time, you can dim an LED, control the speed of a motor, or set the position of a servo. Supported on several GPIO pins of the Pi 5.
PythonA beginner-friendly programming language that is enormously popular for Raspberry Pi projects, data analysis, AI, and web development. Its code reads almost like English. Raspberry Pi OS comes with Python 3 pre-installed, and the Thonny IDE is designed for writing Python.

Q

TermMeaning
Quadrature EncoderAn encoder with two offset signals that reveal not just how far a shaft turned but in which direction. The two "tacho" wires of an NXT motor form a quadrature encoder.
QuantisationA technique for making LLM (AI) models smaller and faster by storing their internal numbers with less precision. For example, a "Q4" quantised model uses 4-bit numbers instead of 32-bit, shrinking it to roughly one-eighth of the size with only a small loss in quality. This is how large AI models can run on the Pi's limited RAM.

R

TermMeaning
RAM (Random Access Memory)Fast, temporary working memory that the CPU uses while programs are running. The Raspberry Pi 5 comes in several RAM sizes (2, 4, 8, or 16 GB) — more RAM lets you run more programs, a desktop, a browser, and even a small AI model at the same time. When you switch the Pi off, RAM is wiped clean.
raspi-configThe official Raspberry Pi configuration tool, launched from the terminal with sudo raspi-config. It gives you a text-based menu for changing settings such as enabling SSH, I2C, SPI, the camera, Wi-Fi country, display resolution, and the hostname — all without needing to edit config files by hand.
Raspberry Pi ConnectAn official remote-access service from the Raspberry Pi Foundation. It lets you securely view and control your Pi's desktop from any web browser, anywhere in the world, without needing to configure port-forwarding on your router.
Raspberry Pi ImagerThe official, free tool from the Raspberry Pi Foundation for writing (flashing) an operating system image to a microSD card. You run it on your main computer (Windows, macOS, or Linux), choose an OS, choose your card, and it downloads, verifies, and writes everything for you. It also lets you pre-configure Wi-Fi, hostname, and SSH before writing.
Reflectance SensorA small sensor (such as the TCRT5000) that shines infra-red light at a surface and measures how much bounces back, so a robot can tell a dark line from a pale floor.
Repository (software)An online library of software packages that apt can download from. The official Raspberry Pi and Debian repositories are already configured on your Pi. Third-party software sometimes asks you to add an extra repository before installing.
ResistorA small electronic component that limits the flow of current. On a breadboard, resistors protect LEDs from burning out. They are colour-coded bands on a tiny cylinder. A 330-ohm resistor is the standard choice when connecting an LED to a 3.3 V GPIO pin.
RGB LEDA single LED containing red, green and blue elements. By mixing their brightness with PWM you can make almost any colour. It comes in common-cathode and common-anode types.
RJ12The small six-wire telephone-style connector LEGO used on NXT motors and sensors. The NXT version has an offset latch, so the plug is keyed differently from a standard phone lead.
Root (filesystem)The very top of the Linux directory tree, written as a single forward slash /. Every file and directory on the system lives somewhere beneath it. It is like the C: drive on Windows, except there is only one tree covering everything.
root (superuser)The all-powerful system administrator account on Linux. The root user can read, change, or delete any file. You become root temporarily by using sudo. Logging in permanently as root is dangerous because a single mistyped command can destroy the entire system.
RTC (Real-Time Clock)A small, battery-backed clock circuit that keeps track of the current time even when the main power is off. The Raspberry Pi 5 has an on-board RTC battery connector. Without a battery in that connector and an internet connection, the Pi's clock resets every time you unplug it.

S

TermMeaning
SalvageRecovering useful parts from broken or unwanted electronics rather than buying new ones — a staple of the maker mindset, and kinder to the planet. See e-waste.
SambaA software package that lets Linux computers (including your Pi) share files and printers with Windows computers on the same network. With Samba, your Pi can appear as a shared drive in Windows Explorer.
scp / SFTPTwo methods for transferring files securely over a network connection. scp (Secure Copy) is a command-line tool. SFTP (SSH File Transfer Protocol) is used by graphical apps like FileZilla. Both tunnel their traffic through SSH, so they are encrypted.
ScriptA text file containing a sequence of commands or programming instructions that the computer runs in order. A Python script ends in .py; a Bash shell script often ends in .sh. Scripts are how you automate repetitive tasks.
ServerA program (or a whole computer) that listens for requests over a network and responds to them. Your Pi can act as a web server, a file server, a media server, or a home-automation server — all at the same time.
ShellA program that interprets the commands you type in a terminal and runs them. The most common shell on Linux is Bash. The shell is what sits between you and the operating system kernel.
SoC (System on a Chip)A single integrated circuit that contains the CPU, GPU, memory controller, and other components all on one piece of silicon. The Raspberry Pi 5's SoC is the Broadcom BCM2712. Packing everything onto one chip makes the Pi small and power-efficient.
SPI (Serial Peripheral Interface)A fast, four-wire communication protocol used to connect components such as display screens, SD card readers, and analogue-to-digital converters to the Pi's GPIO pins. You enable SPI in raspi-config under Interface Options.
SSH (Secure Shell)A way of logging in to another computer over a network and controlling it via a text terminal — all encrypted so nobody can eavesdrop. You use SSH from your main computer (Windows, macOS, or Linux) to connect to your Pi remotely. Enable it in Raspberry Pi OS via sudo raspi-config under Interface Options, or tick the box in the Raspberry Pi Imager before writing your card.
SSH keyA pair of mathematically linked files — a private key (kept on your PC) and a public key (stored on the Pi) — that let you log in via SSH without typing a password. It is both more convenient and more secure than password login. You generate a key pair with ssh-keygen on your PC.
SSD (Solid-State Drive)A storage device with no moving parts that uses flash memory — much faster and more durable than old-style spinning hard drives. An NVMe SSD attached to your Pi via a HAT is the fastest storage option available.
State MachineA way of organising a program around a set of distinct "modes" (states) and the rules for switching between them — for example a robot that is either manually driven, following a target, or avoiding an obstacle.
StorageNon-volatile memory that keeps files even when the power is off. On the Pi, storage is usually a microSD card. You can upgrade to an SSD for much faster performance and longer lifespan.
sudoA command prefix that temporarily grants root (superuser) powers to the current user for one command. You type sudo apt install vlc rather than apt install vlc because installing software requires administrator permission. The name stands for "superuser do".
swapA portion of your storage (microSD or SSD) that the operating system uses as overflow when it runs out of RAM. Because storage is far slower than RAM, heavy swap usage makes the Pi feel sluggish. On a Pi with plenty of RAM, swap is rarely needed, but it acts as a safety net.
systemd / servicesystemd is the system manager that starts and stops everything on modern Linux, including Raspberry Pi OS. A "service" is a background program managed by systemd — for example, a web server or SSH. You control services with sudo systemctl start <name>, sudo systemctl stop <name>, and sudo systemctl enable <name> (to start automatically at boot).

T

TermMeaning
TerminalA program that gives you a text window where you can type commands and see the output. On Raspberry Pi OS Desktop, you open it from the taskbar or by pressing Ctrl + Alt + T. "Terminal", "console", and "command prompt" are often used interchangeably.
ThrottlingWhen the Pi automatically slows its CPU down to prevent overheating. If the chip temperature rises above a threshold (typically 85 °C on the Pi 5), the Pi reduces its speed to generate less heat. An Active Cooler fitted to the Pi prevents throttling under normal conditions.
ThonnyA beginner-friendly Python IDE that comes pre-installed on Raspberry Pi OS. It shows your code on top and the output at the bottom, highlights errors clearly, and includes a simple debugger. It is the recommended way to write Python on the Pi if you are new to programming.
TransistorA tiny electronic switch (or amplifier) controlled by a small current. It lets a weak GPIO signal switch something thirstier — a motor, a speaker, a bright lamp — that a pin could never drive directly.

U

TermMeaning
UART (Universal Asynchronous Receiver/Transmitter)A simple two-wire serial communication interface (one wire for sending, one for receiving) used to connect the Pi to devices such as GPS modules, serial displays, and microcontrollers like the Arduino. Available on the GPIO header; enable it in raspi-config under Interface Options.
ufw (Uncomplicated Firewall)A beginner-friendly command-line tool for managing the Linux firewall. With commands like sudo ufw allow ssh and sudo ufw enable, you can quickly set rules for which network connections are allowed.
Ultrasonic SensorA distance sensor that sends out a pulse of sound too high to hear and times the echo bouncing back. The popular HC-SR04 measures from a few centimetres to a few metres.
UndervoltageWhen the Pi does not receive enough electrical voltage from its power supply. The Pi needs a stable 5.1 V; if it drops below about 4.63 V, a yellow lightning bolt appears in the corner of the screen and performance suffers. Always use the official 27 W USB-C power supply, and avoid cheap or long cables.
UPS (Uninterruptible Power Supply)A battery backup that keeps a device running through a power cut. A Pi UPS HAT does this safely — a better choice than a harvested phone cell for most projects.
USB (Universal Serial Bus)The standard connector family used for keyboards, mice, USB drives, and many peripherals. The Pi 5 has two USB 3.0 ports (blue, fast — up to 5 Gb/s) and two USB 2.0 ports (black, standard speed — up to 480 Mb/s). Use the blue USB 3.0 ports for USB drives or SSDs to get the full speed benefit.
UserAn account on the system with its own files, settings, and permissions. On a fresh Raspberry Pi OS installation, you create your own username during the first-run wizard. Users cannot change system-wide settings without using sudo.

V

TermMeaning
VariableIn programming, a named box that stores a value. In Python, name = "Alice" creates a variable called name holding the text "Alice". Variables let your program remember and work with information.
venv (Virtual environment)An isolated copy of Python — with its own set of installed libraries — that is separate from the system Python. Raspberry Pi OS Bookworm marks the system Python as "externally managed", meaning you cannot install packages into it directly with pip. Create a virtual environment with python3 -m venv myenv, then activate it with source myenv/bin/activate before using pip.
VNC (Virtual Network Computing)A protocol for sharing a graphical desktop over a network. With a VNC client on your main computer (Windows, macOS, or Linux) and VNC enabled on the Pi, you see the Pi's full desktop in a window on that computer and can control it with your mouse and keyboard. Useful when you cannot connect a monitor directly to the Pi.
VoltageThe "pressure" that pushes electrical current through a circuit, measured in volts (V). The Pi's GPIO pins output 3.3 V. The power supply provides 5.1 V. Connecting a 5 V signal directly to a 3.3 V GPIO pin can permanently damage the Pi.
Voltage DividerA pair of resistors that turns a higher voltage into a lower one. It is how you safely feed a 5 V sensor output (such as the HC-SR04’s echo pin) into the Pi’s 3.3 V GPIO.
VoskA free, offline speech-to-text engine light enough to run on a Raspberry Pi. It turns spoken words into text without any internet connection, so your voice never leaves the Pi.

W

TermMeaning
Wake WordA trigger phrase (like “hey robot”) that a device listens for before it starts acting on commands — the same idea as “Hey Siri”, but it can run entirely on your Pi.
WaylandThe modern display system used by Raspberry Pi OS Bookworm to draw windows on screen. It replaces the older X11 system. Most applications work with it transparently. Very occasionally, an old application only supports X11 and you may need to switch or use a compatibility layer called XWayland.
Wi-FiWireless network connectivity using radio waves. The Raspberry Pi 5 has dual-band Wi-Fi (2.4 GHz and 5 GHz) built in. The 5 GHz band is faster but has shorter range; 2.4 GHz has longer range but is often more congested. You configure Wi-Fi during first boot or via the desktop network icon.

X

TermMeaning
X11 / X WindowsThe older display system for Linux desktops, now replaced by Wayland in Raspberry Pi OS Bookworm. You may still encounter it in documentation, and some software still relies on it — in that case XWayland provides backwards compatibility.
xz / tar.xzA compression format used for disk images and other large files. Raspberry Pi OS downloads often end in .img.xz. The Raspberry Pi Imager tool decompresses these automatically when it writes to your card.

Y

TermMeaning
YAMLA human-readable text format used in configuration files, particularly by Docker (docker-compose.yml) and Home Assistant. The name is a recursive acronym standing for "YAML Ain't Markup Language". It uses indentation (spaces, not tabs) to show structure, like an outline. Getting the indentation wrong causes errors, so be careful when editing.

Z

TermMeaning
ZeroconfA set of technologies (including mDNS) that lets devices on a local network find and talk to each other automatically, without manual configuration. It is why you can type raspberrypi.local in a browser and reach your Pi without knowing its IP address.
zip / unzipA very common compression format for bundling files together. You may download zip files of projects or code. On Raspberry Pi OS you can extract them with unzip filename.zip in the terminal, or by right-clicking in the file manager.

Quick reference: abbreviations at a glance

Key terms

  • apt - the command-line tool for installing and updating software on Raspberry Pi OS.
  • Bookworm - the codename for Debian 12, the foundation of the current Raspberry Pi OS.
  • CLI - Command-Line Interface; controlling the computer by typing commands.
  • GPIO - the 40 programmable pins on the Pi used to connect electronic components.
  • gpiozero - the beginner-friendly Python library for controlling GPIO pins.
  • GUI - Graphical User Interface; using a computer through windows and icons.
  • HAT - Hardware Attached on Top; a standard add-on board for the Pi's GPIO header.
  • I2C / SPI / UART - common communication protocols for connecting sensors and modules to the GPIO pins.
  • pip - Python's package installer; on Bookworm, use it inside a virtual environment.
  • PWM - Pulse Width Modulation; technique for producing variable power levels on a digital pin.
  • raspi-config - the official text-menu tool for configuring the Pi's interfaces and settings.
  • Raspberry Pi Imager - the official tool for writing an OS image to a microSD card.
  • RTC - Real-Time Clock; battery-backed clock circuit on the Pi 5 that keeps time when power is off.
  • SSH - Secure Shell; encrypted remote terminal access to the Pi over a network.
  • sudo - a prefix that grants temporary administrator (root) privileges for one command.
  • swap - disk space used as overflow when RAM is full; slower than real RAM.
  • systemd - the system manager that starts and controls background services on the Pi.
  • venv - a Python virtual environment; an isolated Python installation with its own libraries.
  • VNC - Virtual Network Computing; lets you see and control the Pi's desktop remotely.
  • YAML - "YAML Ain't Markup Language"; a human-readable text format used in config files.
