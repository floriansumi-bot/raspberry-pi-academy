The moment you boot your Raspberry Pi 5 for the first time, you are greeted by a clean, friendly desktop that works much like Windows — but with its own personality and a few surprises. This chapter is your guided tour: we will walk every corner of the screen, open every important application, and leave you confident enough to explore on your own.

What You See When You First Log In

After the Raspberry Pi finishes starting up, you land on the Raspberry Pi OS desktop. At first glance it looks like any other computer — there is a background image, some icons, and a bar along the top. That bar is called the taskbar (sometimes called the "panel"), and it is the control centre for everything.

In plain words: A desktop is just the main screen you see after your computer starts — the equivalent of a physical desk where you lay out your work. The taskbar is the strip of buttons and icons that gives you quick access to apps, settings, and the clock.
Note: When you first boot a fresh Raspberry Pi OS Bookworm image, a setup wizard called the Welcome to Raspberry Pi assistant may appear. It will walk you through choosing your country, language, time zone, and a username and password. Complete this wizard before continuing — it sets up the most important personal settings in one go. If you skipped it or it did not appear, do not worry: we will cover all those settings manually in this chapter.

The Taskbar in Detail

The taskbar runs across the very top of the screen. From left to right, you will find:

  • The Raspberry Menu button — the small raspberry icon at the far left. Click it to open the main application menu.
  • Quick-launch icons — small icons for the File Manager, Chromium browser, and Terminal sit right next to the menu button. One click and they open immediately.
  • The window list area — the wide empty middle section. When you open an app, a button for it appears here so you can switch between open windows. Click a button to bring that window to the front; click it again to minimise it.
  • The system tray — a cluster of small icons in the top-right corner for Wi-Fi, Bluetooth, volume, and more. We will look at these shortly.
  • The clock — at the very right, showing the time and date. Click it to see a small calendar.
Tip: If you right-click any empty space on the taskbar, you get options to add or remove panels and applets, so you can customise what lives there over time.

Managing Windows: Minimise, Maximise, Close

Every open application window has three buttons in its top-right corner, just like on Windows:

  • – (minus / dash) — minimises the window (hides it; it stays as a button in the window list area of the taskbar).
  • □ (square) — maximises the window so it fills the whole screen. Click it again to restore it to its previous size.
  • ✕ (cross) — closes the window. If you have unsaved work, the app will ask you to save first.

You can also double-click the title bar of any window to maximise or restore it, and drag the title bar to move the window around the screen.

Click the raspberry icon (top-left) to open the main menu. This is your gateway to every installed application, organised into tidy categories.

The Bundled Applications Worth Knowing

Let us take a closer look at the most useful programs that come pre-installed.

Chromium Web Browser

Chromium is the open-source version of Google Chrome. It looks and behaves almost identically — if you have used Chrome on Windows, you will feel right at home. You can sign in with your Google account to sync bookmarks, use extensions from the Chrome Web Store, and watch videos on YouTube. Find it in Internet → Chromium Web Browser, or click its icon on the taskbar.

Tip: On a Pi 5 with 16 GB of RAM, Chromium runs very well. You can have many tabs open at once without slowdown — something earlier Pis with 2–4 GB struggled with.

File Manager

The File Manager (also called PCManFM) works like Windows Explorer. You can browse folders, copy and paste files, rename things, create new folders, and plug in a USB drive to see its contents. Find it in the taskbar quick-launch area or under Accessories → File Manager.

Key points about the file system on your Pi:

  • Your personal files live in your home folder. If your username is pi this is /home/pi; if you chose a different name during setup (e.g. alice), it is /home/alice. This is equivalent to C:\Users\YourName on Windows. The File Manager opens your home folder by default.
  • The folder called / (just a forward slash, called "root") is the very top of the file system, like C:\ on Windows.
  • USB drives and the microSD card appear automatically on the left side of the File Manager when you plug them in.
  • Right-clicking a file or folder in the File Manager gives you options to copy, cut, paste, rename, delete, or check its properties — just like right-clicking in Windows Explorer.
In plain words: On Linux (which Raspberry Pi OS is built on), file paths use forward slashes (/) instead of backslashes (\) like on Windows. So a folder called "Documents" inside your home folder is written as /home/pi/Documents (or /home/alice/Documents if your username is alice).
Tip: In the File Manager, press Ctrl+H to show hidden files and folders — those whose names start with a dot (such as .config). These are system files and settings that are normally tucked out of sight to keep things tidy. Press Ctrl+H again to hide them.

Text Editor

Under Accessories → Text Editor you will find a simple editor similar to Notepad on Windows — perfect for jotting notes, editing configuration files, or looking at plain text. It does syntax highlighting (colour-coding) for many programming languages, which is handy when you start exploring code.

Thonny Python IDE

Thonny is found in Programming → Thonny. It is a beginner-friendly environment for writing Python programs. Chapter 10 covers Thonny in detail, but for now just know it is there and ready to use — no installation needed.

In plain words: An IDE (Integrated Development Environment) is a program that helps you write, run, and fix code all in one place. Think of it as a very smart text editor that understands programming languages.

Scratch 3

Found in Programming → Scratch 3, Scratch is a visual programming environment where you build programs by snapping colourful blocks together — no typing required. It is wonderfully beginner-friendly and a great way to understand how programming logic works before moving to text-based languages like Python. It is used in schools worldwide and is just as fun for adults learning to code.

LibreOffice (if present)

If your image includes LibreOffice, you will find it under the Office menu. It contains:

  • LibreOffice Writer — a full word processor, very similar to Microsoft Word. It can open and save .docx files.
  • LibreOffice Calc — a spreadsheet program like Microsoft Excel. It can open and save .xlsx files.
  • LibreOffice Impress — a presentation maker like Microsoft PowerPoint. It can open and save .pptx files.

If LibreOffice is not installed, you can add it from Add/Remove Software (covered later in this chapter).

Raspberry Pi Imager

If you ever need to write a new operating system to a microSD card, Raspberry Pi Imager makes it easy. It may already be installed under Accessories → Imager. You choose an OS image from a built-in menu, select your card, and click Write — the tool does the rest. Chapter 3 covers this in full detail; it is mentioned here so you know where to find it.

Terminal

The Terminal is a text-only window where you type commands directly at the computer. It looks intimidating but is incredibly powerful once you are comfortable with it. On Bookworm it is called LXTerminal and lives in Accessories → Terminal, or you can click the black rectangle icon on the taskbar. You can also right-click anywhere on the empty desktop and choose Open Terminal Here to open a Terminal directly in the folder you were looking at.

Chapter 7 is entirely dedicated to using the Terminal, so do not worry about it for now — just know where to find it.

The System Tray: Wi-Fi, Bluetooth, Volume and More

The cluster of small icons in the top-right corner of the taskbar is called the system tray. Each icon is called an applet — a tiny mini-program that controls one aspect of your system.

In plain words: An applet is just a very small program that lives in the taskbar and lets you control one specific thing — like the volume or the Wi-Fi connection — with a single click.

Wi-Fi Applet

Click the network icon (it looks like signal-strength bars or a pair of computers) to see available Wi-Fi networks. Click your network name, type the password when prompted, and you are connected. Once connected, the icon shows your signal strength. If you are using a wired Ethernet cable instead of Wi-Fi, this applet shows two small rectangles (representing network plugs).

Tip: The Pi 5 supports both 2.4 GHz and 5 GHz Wi-Fi. If your router offers both, pick the 5 GHz network for faster speeds — it will usually have "5G" or "5GHz" somewhere in its name.

Bluetooth Applet

Click the Bluetooth icon (a stylised "B" shape) to open the Bluetooth manager. From here you can pair a wireless keyboard, mouse, or headphones. Click Add Device, put your device into pairing mode (check its manual), and the Pi will find it automatically.

Note: Remember that the Pi 5 has no headphone jack. If you want audio through speakers or headphones, you need either HDMI audio (your TV or monitor's built-in speakers), a USB audio adapter, or a Bluetooth speaker or headphones paired through this applet.

Volume Applet

Click the speaker icon to see a volume slider. Drag it left to go quieter, right to go louder. Right-click the same icon to choose which audio output device to use — for example, switching between HDMI audio and a USB speaker.

Eject / Removable Media

When you plug in a USB drive, an eject icon appears in the system tray. Always click this icon and choose "Eject" before unplugging a USB drive. This tells the Pi to finish writing any data before the drive is removed, preventing file corruption.

Careful: Pulling out a USB drive without ejecting it first can corrupt the files on that drive — just like on Windows. Always eject first, then unplug.

Software Update Notifications

A small shield or update icon sometimes appears in the system tray to let you know that software updates are available. Click it to open a graphical update manager that lists what will be updated and lets you apply the changes with one click. Keeping your software up to date is important for security and stability, so do not dismiss these notifications — install the updates when you have a few spare minutes.

Clock and Calendar

Click the clock in the top-right corner to pop up a small calendar. You can scroll through months. The time is set automatically if you are connected to the internet (the Pi uses a service called NTP — Network Time Protocol — to sync with internet time servers).

In plain words: NTP (Network Time Protocol) is an invisible background service that checks the correct time over the internet and keeps your computer's clock accurate. You never need to touch it.

Preferences: Raspberry Pi Configuration

Go to Raspberry Menu → Preferences → Raspberry Pi Configuration. This is the most important settings window on your Pi — a one-stop shop for tuning how the system works. It has five tabs. Let us go through each one.

Note: Some changes in this window require a reboot to take effect. The Pi will tell you when that is necessary.

System Tab

This tab controls fundamental behaviour:

  • Password — change the password for your user account. Do this early if you have not already. The default password on older images is well known and is a security risk on any network.
  • Hostname — the name your Pi announces on the local network. Change it from the default raspberrypi to something personal like florians-pi (use only letters, numbers, and hyphens — no spaces).
  • Boot — choose whether the Pi boots straight to the desktop (recommended for beginners) or to a command-line screen.
  • Auto login — when enabled, the Pi skips the login screen and goes straight to the desktop. Convenient at home; turn it off if others can access the machine.
  • Network at Boot — if ticked, the Pi waits for a network connection before finishing start-up. Useful if you have services that need the internet immediately.
  • Splash screen — the decorative image shown during boot. You can turn it off to see the technical boot messages instead (useful when diagnosing problems).
Tip: Changing your password is the single most important security step for a Pi on any network. Go to the System tab now and set a strong password you will remember.

Display Tab

Controls what appears on your screen:

  • Headless Resolution — if you ever run the Pi without a monitor attached (called "headless"), this sets the virtual screen size used for remote desktop access.
  • Underscan — on some older TVs, the edges of the screen are cut off or have a black border. Toggle this to fix it.
  • Pixel Doubling — makes everything appear twice as large. Useful on very high-resolution monitors where text is tiny.
  • Screen Blanking — if enabled, the screen turns off after a period of inactivity to save power. Disable it if you find your screen going black annoyingly.
In plain words: Headless means running the Pi without a keyboard, mouse, or monitor connected directly — you control it entirely from another computer over the network. It is a common setup once you are more comfortable with the Pi.

Interfaces Tab

This tab switches on or off various technical connections. By default most are off to keep the system secure:

Interface What It Does When to Enable
SSH Lets you control the Pi remotely from another computer using a text terminal When you want to log in from your Windows PC without a keyboard on the Pi
VNC Lets you see and control the Pi's full desktop from another computer When you want to use the Pi remotely with a graphical screen
SPI A communication bus for certain electronics add-ons When connecting specific sensors or displays to the GPIO pins
I2C Another communication bus for electronics add-ons When connecting I2C-compatible sensors (temperature, pressure, etc.)
Serial Port Enables the hardware serial connection on GPIO pins When connecting GPS modules, Arduino boards, or similar devices
1-Wire A simple bus used mainly for temperature sensors When using a DS18B20 temperature sensor
Remote GPIO Allows another computer to control the Pi's GPIO pins over the network Advanced use only
Careful: Only enable SSH and VNC if you need them. Leaving unnecessary interfaces enabled widens the attack surface of your Pi, especially on a shared or public network. Enable them only after you have set a strong password.

Performance Tab

This tab lets you adjust how hard your Pi works:

  • GPU Memory — how much RAM (in megabytes) is reserved for the graphics chip. On Raspberry Pi OS Bookworm, graphics memory is largely managed automatically using a modern system called CMA (Contiguous Memory Allocation), so the default value of 128 MB works well for everyday use. You generally do not need to change this unless a specific application asks you to.
  • Overlay File System — an advanced option that makes the microSD card read-only to protect it from corruption. Leave it off unless you have a specific reason.
  • Fan — the Pi 5 has a connector for the Active Cooler's fan. This panel lets you choose between always-on, temperature-controlled (recommended), or off. Temperature-controlled is the default: the fan spins up when the chip gets warm and quietens down when it cools.
In plain words: GPU stands for Graphics Processing Unit — the part of the chip that draws images on your screen. CMA (Contiguous Memory Allocation) is a behind-the-scenes technique that lets the system share RAM between the main processor and the graphics chip intelligently, rather than permanently reserving a fixed chunk for graphics.

Localisation Tab

This tab makes your Pi feel at home in your country:

  • Locale — sets the language, number format, and date format. For the UK choose en_GB.UTF-8; for France choose fr_FR.UTF-8; for Germany de_DE.UTF-8; for Switzerland you can choose any of the four national languages.
  • Timezone — sets the region and city for your local time. Pick the nearest city in your timezone (e.g. Europe/London, Europe/Paris, Europe/Zurich).
  • Keyboard — sets the keyboard layout. If your keyboard has different symbols than what appears on screen, this is what to change (e.g. gb for a UK keyboard, fr for a French AZERTY keyboard, de for a German QWERTZ keyboard).
  • Wi-Fi Country — sets the radio regulations for Wi-Fi. Always set this to your country — using Wi-Fi channels not permitted locally is illegal in most jurisdictions.
Tip: If you find that pressing Shift+2 gives you " instead of @, or the @ and " keys are swapped, the keyboard layout is set wrong. Go to the Localisation tab and correct it immediately — it affects everything you type.

Screen Configuration Tool

Go to Raspberry Menu → Preferences → Screen Configuration. This tool opens a graphical editor that shows your physical monitors as rectangles. The Pi 5 has two micro-HDMI ports, so it can drive two separate monitors at once.

With Screen Configuration you can:

  • Drag the monitor rectangles to set which screen is "left" and which is "right" — matching your physical desk layout.
  • Set the resolution and refresh rate for each screen. The Pi 5 supports up to 4K (3840 × 2160) at 60 frames per second on each port.
  • Mirror or extend — "mirror" shows the same picture on both screens; "extend" gives you one large continuous desktop spread across both.
  • Rotate a screen — useful if you mount a monitor in portrait orientation.

After making changes, click Apply in the top-left corner of the Screen Configuration tool, then confirm the change within a few seconds (the tool reverts automatically if you do not confirm, so you cannot lock yourself into a broken display).

Note: If you use only one monitor, plug the HDMI cable into the micro-HDMI port labelled HDMI0 — it is the one closest to the USB-C power socket. The Pi 5 defaults to HDMI0 as the primary display.

Changing the Appearance and Desktop Background

Go to Raspberry Menu → Preferences → Appearance Settings. This window has several tabs:

  • Desktop — change the background image or colour. You can pick from the built-in images, or click the folder icon to choose any image file from your home folder. You can also set different backgrounds on each monitor if you have two screens.
  • Menu Bar — change the colour and size of the taskbar, and the size of the icons in it.
  • System — choose a theme (controls the colour of window borders, buttons, and menus). The built-in choices include light and dark variants.
  • Defaults — a set of preset combinations of wallpaper, theme, and icon style. A quick way to give your desktop a completely different look.

You can also right-click anywhere on the empty desktop and choose Desktop Preferences to jump straight to the background settings.

Tip: You can use any JPEG or PNG image as your wallpaper. Download a photo you love in Chromium, save it to your Pictures folder (in your home folder), and set it as your wallpaper here.

Add / Remove Software: The Graphical App Store

Go to Raspberry Menu → Preferences → Add / Remove Software. This opens a window that works much like an app store — you can search for free software, tick what you want, and click OK to install it automatically.

Behind the scenes it is using Debian's software archive, which contains tens of thousands of free and open-source programs. Everything is free of charge and safe to install from this source.

Installing an App (Step by Step)

  1. Open Raspberry Menu → Preferences → Add / Remove Software.
  2. Type what you are looking for in the search box at the top (for example, type vlc to find the VLC media player).
  3. A list of matching programs appears. Read the short description next to each result to make sure you have the right one.
  4. Tick the checkbox next to the program you want.
  5. Click OK. You will be asked for your password.
  6. The Pi downloads and installs the software. This may take a minute or two, depending on the size of the program and your internet speed.
  7. Once done, the program appears in the appropriate menu category. It is ready to use immediately — no restart required.
Note: To remove an app you no longer want, open Add / Remove Software, search for it, un-tick its checkbox, and click OK. This frees up space on your microSD card.

Installing Software from the Terminal

Power users often install software faster by typing a single command in the Terminal. The command tool that manages software on Raspberry Pi OS is called apt. Here is how to install VLC as an example:

sudo apt update

sudo apt update — Downloads the latest list of available software from Debian's servers on the internet. Think of it as refreshing the app store catalogue so the system knows about the newest versions. sudo means "run this as administrator" (short for "superuser do") — some commands need elevated permission to make system-level changes. You will be asked for your password.

sudo apt install vlc

sudo apt install vlc — Tells the package manager to download and install the program called vlc. The Pi will ask you to confirm by pressing Y then Enter. Replace vlc with the name of any program you want to install — for example, sudo apt install libreoffice to install the full LibreOffice suite.

In plain words: sudo is like clicking "Run as Administrator" on Windows — it temporarily grants you the highest level of permission to make system-level changes. You will be asked for your password the first time you use it in a Terminal session. On subsequent commands in the same session it remembers for a few minutes.
Careful: Only run sudo commands from a trustworthy source — the official Raspberry Pi documentation, this book, or a well-known tutorial site. A malicious sudo command has the power to make serious, hard-to-reverse changes to your system.
Note: On Raspberry Pi OS Bookworm, if you try to install a Python package by typing pip install something without any extra steps, you will see an error saying the environment is "externally managed". This is a protection to prevent accidentally breaking the system. For Python packages, use Thonny's built-in package manager, install them with sudo apt install python3-packagename, or use a virtual environment (Chapter 10 explains all of these).

Keeping Your Software Up to Date

Software updates bring security fixes, bug corrections, and new features. On Raspberry Pi OS Bookworm, updates arrive in two ways:

  • Graphically — a shield icon appears in the system tray when updates are ready. Click it and follow the prompts to apply them.
  • From the Terminal — run the two commands below. Many guides combine them onto one line, but here they are shown separately so you can see exactly what each one does.
sudo apt update
sudo apt upgrade

Line 1 — sudo apt update: Contacts the Debian software servers and downloads an up-to-date list of all available packages and their latest version numbers. This does not install anything yet — it just refreshes the catalogue.

Line 2 — sudo apt upgrade: Compares your currently installed software against the catalogue just downloaded, then downloads and installs any newer versions it finds. You will be shown a list of what will be upgraded and asked to confirm with Y then Enter.

Tip: Run these two commands every week or two. It is one of the best habits you can build. If the system suggests a reboot afterwards, do so to make sure all updates are fully active.

How to Shut Down and Reboot — and Why It Matters

This is one of the most important habits to build. Never just unplug the power cable to turn off the Pi. Raspberry Pi OS, like all Linux systems, constantly writes data to the microSD card in the background. If you cut the power mid-write, you can corrupt the file system — sometimes badly enough that the card will not boot.

Careful: Unplugging the Pi while it is running is the most common cause of microSD card corruption for new users. Always shut down properly through the menu or with the power button first, then wait for the activity light to go out before unplugging.

Shutting Down from the Menu

  1. Click the Raspberry Menu (top-left raspberry icon).
  2. Click Shutdown at the bottom of the menu.
  3. A small window appears with three buttons: Shutdown, Reboot, and Logout.
  4. Click Shutdown to turn the Pi off completely, or Reboot to restart it.
  5. Wait until the screen goes dark and the green activity light on the Pi stops flashing. Then — and only then — you can safely unplug the power.

Shutting Down from the Terminal

If you are already working in a Terminal window, you can shut down or reboot with a command. Run one or the other — not both at the same time:

sudo shutdown now

sudo shutdown now — Immediately begins a safe shutdown. The Pi saves everything, stops all running programs cleanly, and powers itself off. Wait for the green activity LED to go dark before removing power.

sudo reboot

sudo reboot — Cleanly restarts the Pi, as if you chose Reboot from the Raspberry Menu. Use this after installing updates or making configuration changes that require a restart.

Using the Physical Power Button

The Raspberry Pi 5 has a small physical button on the board (usually accessible through a small hole in the lid of your case). A single short press initiates a safe, clean shutdown — exactly the same as choosing Shutdown from the menu. This is the quickest and safest way to power off if your keyboard or mouse is not responding.

Note: Holding the power button down for several seconds forces an immediate power cut without saving — only do this as a last resort if the Pi is completely frozen and will not respond to anything.

Exploring Safely: Good Habits from Day One

The desktop is yours to explore, and you really cannot break anything simply by opening apps and clicking menus. Here are a few habits that will keep your Pi healthy:

  • Always shut down properly — never unplug the power mid-session.
  • Keep software updated — security fixes and improvements arrive regularly. Run sudo apt update followed by sudo apt upgrade in the Terminal every week or two, or click the shield icon in the system tray when it appears.
  • Set a strong password — do this in Raspberry Pi Configuration → System as soon as possible if you have not already.
  • Eject USB drives before unplugging — use the system tray eject icon.
  • Read error messages — the Pi usually tells you in plain language when something goes wrong. Do not just click OK without reading.
  • Back up your microSD card — Chapter 13 covers this. A microSD card can wear out or get corrupted; a backup means you can be back up and running in minutes.
Tip: If you accidentally delete something from the File Manager, open the Wastebasket — right-click the bin icon on the desktop and choose Open, or look for it in the File Manager's left-hand panel. Files deleted from the File Manager go there first, just like the Recycle Bin on Windows. Files deleted from the Terminal, however, are gone immediately — the Terminal has no wastebasket.

Key terms

  • Taskbar — the strip along the top of the screen containing the menu, quick-launch icons, window list, system tray applets, and clock.
  • Applet — a tiny program embedded in the taskbar that controls one aspect of your system (Wi-Fi, volume, etc.).
  • System tray — the cluster of small applet icons in the top-right corner of the taskbar.
  • Raspberry Menu — the main application launcher, opened by clicking the raspberry icon at the top-left of the taskbar.
  • Chromium — the open-source web browser included with Raspberry Pi OS, almost identical to Google Chrome.
  • Thonny — a beginner-friendly Python programming environment pre-installed on the Pi.
  • Scratch 3 — a visual, block-based programming environment great for learning coding concepts without typing code.
  • LibreOffice — a free, open-source office suite compatible with Microsoft Office file formats (.docx, .xlsx, .pptx).
  • Terminal — a text-based window where you type commands directly at the system; covered in depth in Chapter 7.
  • SSH — Secure Shell; a way to control the Pi remotely from another computer's terminal over a network.
  • VNC — Virtual Network Computing; lets you see and control the full Pi desktop from another computer over a network.
  • GPU — Graphics Processing Unit; the part of the chip that handles drawing images and video on your screen.
  • CMA — Contiguous Memory Allocation; a modern technique used on Bookworm to share RAM flexibly between the processor and graphics chip.
  • Locale — a setting that tells the system which language, number format, and date format to use.
  • Headless — running the Pi without a directly connected keyboard, mouse, or monitor; controlled remotely over the network.
  • apt — the command-line software manager for Debian/Raspberry Pi OS; used to install, update, and remove programs.
  • sudo — a prefix for commands that need administrator-level permission; equivalent to "Run as Administrator" on Windows.
  • NTP — Network Time Protocol; a background service that keeps your Pi's clock accurate by syncing with internet time servers.
  • Shutdown — the safe process of stopping all software and powering off the Pi without corrupting data.

  • Good habits — proper shutdown, regular updates, a strong password, and USB ejection — protect your Pi from the most common everyday problems.
