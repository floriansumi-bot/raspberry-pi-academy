This appendix is your quick-reference companion — a single place to look up every important command covered in the book, grouped by topic so you can find what you need in seconds. Keep it bookmarked, dog-eared, or printed out; you will reach for it again and again.

Note: Every command here is typed at the terminal prompt — the black window you open from the taskbar or by pressing Ctrl + Alt + T on Raspberry Pi OS. The $ sign at the start of examples is not something you type; it simply represents the prompt itself.

How to Read This Appendix

Each section contains a table. The left column shows the exact command (or the most common form of it). The right column gives a one-sentence plain-English description of what it does. Where a command needs a placeholder — something you replace with your own value — it is shown in italics inside angle brackets, for example <folder>.

In plain words: A command is a short text instruction you type into the terminal to make the Pi do something. Think of it as sending a text message to the computer — it reads it and responds immediately.

1 — Navigating the File System

These commands let you move around the folder structure of your Pi, just like clicking through folders on Windows Explorer.

Command What it does
pwd Print Working Directory — shows the full path of the folder you are currently inside.
ls List the files and folders in the current directory.
ls -la List everything (including hidden files) with full details: permissions, owner, size, and date.
cd <folder> Change Directory — move into the named folder.
cd .. Go up one level to the parent folder (two dots means "one level up").
cd ~ Go straight to your home folder (e.g. /home/pi or /home/<yourname>) from anywhere.
cd / Go to the very top (root) of the file system.
tree Show the current folder and all its contents as a visual tree (install with sudo apt install tree if missing).
tree -L 2 Same tree view but limited to two levels deep — useful for large folders.
Tip: Press the Tab key after typing the first few letters of a folder or file name and the terminal will try to complete it for you automatically. This saves typing and prevents spelling mistakes.

2 — Working with Files and Folders

These commands let you create, copy, move, view, and delete files — the everyday tasks you would normally do with a mouse in Windows Explorer.

Command What it does
mkdir <name> Make Directory — create a new folder with the given name.
mkdir -p <path/to/folder> Create the folder and any missing parent folders in one go (-p means "parents").
touch <file> Create an empty file (or update its timestamp if it already exists).
cp <source> <destination> Copy a file from one place to another.
cp -r <folder> <destination> Copy a whole folder and everything inside it (-r means "recursive").
mv <source> <destination> Move (or rename) a file or folder.
rm <file> Remove (permanently delete) a file. There is no Recycle Bin on Linux.
rm -r <folder> Delete a folder and all its contents recursively.
nano <file> Open a file in the Nano text editor. Use Ctrl+O to save and Ctrl+X to quit.
cat <file> Print the entire contents of a file directly to the terminal screen.
less <file> View a file one page at a time — useful for long files. Press q to quit.
head -n 20 <file> Show only the first 20 lines of a file.
tail -n 20 <file> Show only the last 20 lines of a file.
tail -f <file> Follow a file live — new lines are printed as they are added (useful for watching log files). Press Ctrl+C to stop.
grep "<word>" <file> Search for a word or phrase inside a file and print every matching line.
grep -r "<word>" <folder> Search for a word inside every file in a folder and all its sub-folders.
find . -name "<pattern>" Search for files matching a name pattern inside the current folder and all sub-folders (e.g. find . -name "*.py" finds all Python files).
Careful: rm deletes files immediately and permanently — there is no undo and no Recycle Bin. Double-check what you type before pressing Enter. Never run rm -rf / — it would attempt to erase everything on the Pi.

3 — Permissions

Linux keeps careful track of who is allowed to read, change, or run each file. These commands control those rules.

In plain words: Permissions are a set of rules attached to every file that decide who can read it, write to it, or run it as a program. Think of them like a lock on a filing cabinet — only authorised people have the key.
Command What it does
sudo <command> Run any command as the system administrator ("superuser"). You will be asked for your password the first time in a session.
chmod +x <file> Make a file executable — allows you to run it as a program.
chmod 644 <file> Set standard file permissions: owner can read & write; everyone else can only read.
chmod 755 <file> Set standard program permissions: owner can read, write & run; everyone else can read & run.
chown <user>:<group> <file> Change the owner (and optionally the group) of a file.
chown -R <user>:<user> <folder> Give a specific user ownership of a folder and everything inside it (-R means "recursive"). Replace <user> with your actual username (e.g. pi).
ls -l <file> Show a file's current permissions in detail — the string of r, w, and x letters tells you who can read, write, and execute it.
whoami Print the name of the currently logged-in user.
groups List all the groups the current user belongs to (useful for checking GPIO and camera access).
sudo usermod -aG <group> <user> Add a user to a group (e.g. sudo usermod -aG gpio pi gives the pi user access to GPIO pins). Log out and back in for the change to take effect.
Tip: If a command refuses with "Permission denied", try putting sudo in front of it. But only use sudo when genuinely needed — running everything as superuser all the time is risky, like always working as a Windows Administrator.

4 — Installing and Managing Software

Raspberry Pi OS uses a tool called apt (Advanced Package Tool) to download and install software from the internet — similar to an app store, but operated entirely from the terminal.

In plain words: A package is a bundle containing a program plus everything it needs to run. The package manager (apt) handles downloading, installing, and updating packages for you automatically.
Command What it does
sudo apt update Refresh the list of available packages and their latest versions (does NOT yet install anything).
sudo apt full-upgrade Download and install all available updates to packages already on your Pi (preferred over apt upgrade on Raspberry Pi OS).
sudo apt install <package> Download and install a specific package (e.g. sudo apt install tree).
sudo apt install <pkg1> <pkg2> Install multiple packages in one command by listing their names separated by spaces.
sudo apt remove <package> Uninstall a package, but keep its configuration files.
sudo apt purge <package> Uninstall a package and delete its configuration files completely.
sudo apt autoremove Remove packages that were installed as dependencies but are no longer needed by anything.
apt search <keyword> Search the package list for programs matching a keyword (no sudo needed for searching).
apt show <package> Show detailed information about a package before you install it.
dpkg -l | grep <name> Check whether a particular package is already installed on your Pi.
apt list --installed List every package currently installed on the Pi.
Note: Always run sudo apt update before sudo apt full-upgrade or sudo apt install. The update step fetches the current catalogue; without it, apt may try to install an outdated version.

One-line Recipe: Update Everything

To refresh, upgrade, and tidy up in a single command, you can chain these three instructions together with && (which means "and then, only if the previous step succeeded"):

sudo apt update && sudo apt full-upgrade -y && sudo apt autoremove -y

sudo apt update — fetches the latest list of available packages from the internet.

&& — only runs the next command if the previous one finished without errors.

sudo apt full-upgrade -y — installs all available updates; -y automatically answers "yes" to any confirmation prompts.

&& sudo apt autoremove -y — removes any packages that are no longer needed, keeping your Pi tidy.

5 — Python on Raspberry Pi OS Bookworm

Python 3 is pre-installed on Raspberry Pi OS. However, since the Bookworm release (Debian 12), the system Python is externally managed — meaning you cannot install Python libraries into it with plain pip install without extra steps. This protects the operating system from accidentally broken packages. Here is what to use instead.

In plain words: A virtual environment (venv) is a private, self-contained copy of Python just for one project. Libraries you install there do not affect anything else on the Pi. Think of it as a separate toolbox for each job.
Command What it does
python3 --version Show which version of Python 3 is installed.
python3 <script.py> Run a Python script file.
python3 -m venv <name> Create a new virtual environment in a folder called <name> (e.g. python3 -m venv myenv).
source <name>/bin/activate Activate the virtual environment — your prompt will change to show its name. Now pip install is safe to use.
deactivate Leave the virtual environment and return to the normal system Python.
pip install <library> Install a Python library — only run this after activating a virtual environment.
pip list Show all libraries installed in the current virtual environment.
pip freeze > requirements.txt Save the list of installed libraries to a file (useful for recreating the same environment later).
sudo apt install python3-<name> Install a Python library as a system package via apt — the safe alternative to pip for the system Python (e.g. sudo apt install python3-pygame).
thonny Launch the Thonny IDE — the beginner-friendly Python editor that comes pre-installed and manages its own Python environment safely.
Careful: On Raspberry Pi OS Bookworm, running pip install <library> directly (without activating a virtual environment first) will produce an error: "externally-managed-environment". This is intentional. Either activate a virtual environment first, or install via sudo apt install python3-<name>.

6 — System Information

These commands let you peek under the bonnet of your Pi — checking temperature, memory, disk space, and more.

Command What it does
df -h Show disk space usage for all storage drives in human-readable sizes (GB/MB).
free -h Show how much RAM is being used and how much is still free, in human-readable form.
vcgencmd measure_temp Report the current CPU temperature (e.g. temp=47.8'C) — great for checking if your Active Cooler is working.
vcgencmd get_throttled Check whether the Pi is throttling (slowing down) due to overheating or low voltage. 0x0 means all is well; any other value flags a problem.
vcgencmd measure_volts core Show the current core voltage — useful for diagnosing under-voltage warnings.
hostname -I Show the IP address(es) assigned to your Pi on the local network.
uname -a Print detailed information about the operating system kernel version and hardware architecture.
cat /proc/cpuinfo Show detailed CPU information including the hardware model — confirm it shows a Raspberry Pi 5.
cat /etc/os-release Show which version of Raspberry Pi OS (Bookworm, etc.) is installed.
fastfetch Display a colourful system summary (CPU, RAM, OS version, uptime). Install with sudo apt install fastfetch if missing.
top Show a live, updating list of running programs and their CPU/memory usage. Press q to quit.
htop A friendlier, colour-coded version of top. Install with sudo apt install htop if missing.
uptime Show how long the Pi has been running since it was last switched on.
lsusb List all USB devices currently plugged in to your Pi.
lsblk List all storage devices and partitions (useful for spotting USB drives or NVMe SSDs).
lspci List devices connected on the PCIe bus — on the Pi 5 this includes any NVMe SSD fitted to an M.2 HAT.
Tip: Run vcgencmd measure_temp a few minutes after the Pi has been on and working hard. A healthy temperature with the Active Cooler fitted is typically 40–60 °C under load. Anything consistently above 80 °C is worth investigating — check that the cooler fan is spinning.

Throttling Status Quick-Reference

The number returned by vcgencmd get_throttled is a bitmask. Here are the most common values and what they mean:

Value Meaning
0x0 All clear — no problems detected.
0x1 Under-voltage currently detected — check your power supply. The official 27 W USB-C supply is recommended.
0x2 Arm frequency is currently being throttled (speed reduced) due to heat or voltage.
0x4 Currently throttled — the Pi is running slower than normal.
0x50000 Under-voltage has occurred since last boot (even if not happening right now).

7 — Managing Services

A service (also called a daemon) is a program that runs in the background — for example the web server, SSH, or your own Python scripts set to start at boot. The systemctl command controls them all.

In plain words: A service is a background program that keeps running quietly without a window, doing a job such as serving web pages or listening for SSH connections. systemctl is like the master on/off switch for every background program on the Pi.
Command What it does
systemctl status <service> Show whether a service is running or stopped, and its recent log messages.
sudo systemctl start <service> Start a service immediately (until the next reboot).
sudo systemctl stop <service> Stop a running service immediately.
sudo systemctl restart <service> Stop then start a service — useful after changing its configuration file.
sudo systemctl reload <service> Ask a service to re-read its configuration without fully stopping (not all services support this).
sudo systemctl enable <service> Make a service start automatically every time the Pi boots.
sudo systemctl disable <service> Stop a service from starting automatically at boot (it can still be started manually).
systemctl list-units --type=service --state=running List every service that is currently running — useful when you cannot remember the exact service name.
journalctl -u <service> Show the full log history for a specific service — helpful for diagnosing errors.
journalctl -u <service> -f Follow a service's log live — new lines appear as they are written. Press Ctrl+C to stop.
journalctl -xe Show recent system-wide log messages, jumping to the end — useful when something just went wrong.
journalctl --since "1 hour ago" Show all log messages from the last hour.
Note: Replace <service> with the actual service name, for example ssh, nginx, or bluetooth. Common services you will encounter: ssh (remote access), NetworkManager (Wi-Fi), cron (scheduled tasks), pigpiod (GPIO daemon).

8 — Networking

These commands help you check your network connection, find your Pi's address on the network, and connect to other computers remotely.

Command What it does
ping <address> Send test packets to a host (e.g. ping google.com) to check whether it is reachable. Press Ctrl+C to stop.
ping -c 4 <address> Send exactly 4 test packets then stop automatically.
ip a Show all network interfaces and their IP addresses (the modern replacement for the older ifconfig command).
ip route Show the routing table — useful for finding your router's (gateway's) IP address.
hostname -I Print just the Pi's own IP address(es) in a clean format — the quickest way to look it up.
nmcli device status Show the status of all network interfaces — whether Wi-Fi and Ethernet are connected.
nmcli device wifi list List all nearby Wi-Fi networks visible to the Pi.
nmcli device wifi connect "<SSID>" password "<pass>" Connect to a Wi-Fi network from the terminal. Replace <SSID> with the network name and <pass> with its password.
ssh <user>@<address> Open a secure remote terminal session to another computer (e.g. ssh pi@192.168.1.42).
ssh -p <port> <user>@<address> Connect via SSH on a non-standard port number.
scp <file> <user>@<address>:<path> Securely copy a file to a remote computer over SSH.
scp <user>@<address>:<file> . Securely copy a file FROM a remote computer to your current local folder (the dot at the end means "here").
curl -I <url> Fetch only the headers from a web URL — a quick way to check whether a web server is responding.
wget <url> Download a file from the internet to the current folder.
Note: The older iwconfig command (for Wi-Fi details) is deprecated on Bookworm and may not be installed. Use nmcli device status or nmcli device wifi list instead — these work correctly with Raspberry Pi OS Bookworm's NetworkManager.

One-line Recipe: Find Your Pi's IP Address from Windows

If you are on Windows and want to find your Pi without logging in to it, open a Command Prompt on your Windows PC and type:

ping raspberrypi.local

ping raspberrypi.local — sends a test packet to the hostname raspberrypi.local. If the Pi is on the same network, it will reply and Windows will show its IP address in the output. You can then use that IP to connect via SSH or a web browser. If you changed the hostname in raspi-config, substitute your custom name — e.g. ping mypihostname.local.

9 — Power and Configuration

These commands control the Pi's power state and open the main configuration tool.

Careful: Always shut the Pi down gracefully with one of the commands below before cutting the power. Yanking the power cable while the Pi is running can corrupt the microSD card, just like pulling a USB drive out of a Windows PC while files are being written to it.
Command What it does
sudo reboot Safely restart the Pi — it will shut everything down and then boot up again.
sudo shutdown -h now Safely shut the Pi all the way down to a powered-off state immediately (-h means "halt").
sudo shutdown -h +5 Schedule a safe shutdown in 5 minutes — gives others time to save their work.
sudo shutdown -r 22:00 Schedule a reboot at 10 pm tonight (-r means "reboot").
sudo shutdown -c Cancel a scheduled shutdown or reboot before it happens.
sudo raspi-config Open the Raspberry Pi Configuration tool — a text menu for changing settings such as hostname, Wi-Fi country, SSH, locale, and display resolution.
sudo raspi-config nonint do_ssh 0 Enable SSH from the command line without entering the menu (0 = enable, 1 = disable).
Tip: The Pi 5 has a small physical power button on the board (next to the USB-C socket). A short press initiates a safe shutdown; once the green LED stops flashing, it is safe to disconnect the power. Press again to switch it back on.

10 — Helpful Keyboard Shortcuts in the Terminal

These shortcuts work in almost any Linux terminal and will save you enormous amounts of time once they become habit.

Shortcut What it does
Tab Auto-complete a filename or command. Press twice to see all possibilities if there is more than one match.
↑ / ↓ Scroll through your command history — press Up to repeat the previous command, Down to move forward again.
Ctrl+C Cancel (stop) a running command immediately.
Ctrl+D Close the terminal session (sends an end-of-input signal, equivalent to typing exit).
Ctrl+L Clear the terminal screen (same as typing the clear command).
Ctrl+A Jump to the beginning of the current line.
Ctrl+E Jump to the end of the current line.
Ctrl+U Delete everything from the cursor back to the start of the line — useful for quickly clearing a mistyped command.
Ctrl+Z Suspend (pause) the current program and return to the prompt. Type fg to bring it back to the foreground.
Ctrl+R Search backwards through your command history — start typing any part of a previous command to find it.
history Print a numbered list of your recent commands.
!<number> Re-run a command from your history by its number (e.g. !42 runs command number 42).
!! Repeat the very last command you ran — extremely useful as sudo !! if you forgot to type sudo.
clear Clear all text from the terminal screen (same as Ctrl+L).
exit Close the terminal session (same as Ctrl+D).

11 — Pipes, Redirects and Other Useful Tricks

These are not commands by themselves but special characters you can combine with commands to do more powerful things in a single line.

In plain words: A pipe (the | character) connects two commands so that the output from the first flows directly into the input of the second — like connecting garden hoses end-to-end. A redirect (>) sends output into a file instead of the screen.
Symbol / Example What it does
command1 | command2 Pipe — sends the output of command1 as the input to command2 (e.g. ls -la | less lets you scroll a long file listing).
command > file.txt Redirect — saves the output of a command into a file, overwriting any existing content.
command >> file.txt Append redirect — adds the output to the end of an existing file without overwriting it.
command1 && command2 Run command2 only if command1 succeeded without errors.
command1 || command2 Run command2 only if command1 failed — useful as a fallback.
command1 ; command2 Run command2 after command1 regardless of whether command1 succeeded.
command & Run a command in the background so the terminal is free immediately for your next command.
grep "text" file | wc -l Count how many lines in a file contain a specific word (wc -l counts lines).
ls -la | grep ".py" List only the Python files in the current folder by filtering the output with grep.
2>/dev/null Silently discard error messages — append this to a command to suppress "Permission denied" noise.

One-line Recipe: Quickly Check Temperature Every 2 Seconds

watch -n 2 vcgencmd measure_temp

watch — runs a command repeatedly and refreshes the display on a fixed interval.

-n 2 — sets the interval to 2 seconds.

vcgencmd measure_temp — the command being repeated; it reads and reports the CPU temperature.

The result is a live temperature display that updates every 2 seconds. Press Ctrl+C to stop.

One-line Recipe: Find the Biggest Files Eating Your Disk Space

sudo du -sh /home/* /var/* /tmp/* 2>/dev/null | sort -rh | head -20

sudo du -sh — estimates disk usage of each listed path; -s gives a summary per item and -h shows sizes in human-readable form (MB, GB). sudo is used so that protected folders are not skipped.

/home/* /var/* /tmp/* — the folders most likely to hold large user files and temporary data.

2>/dev/null — silently discards any "Permission denied" error messages so the output stays clean.

| sort -rh — pipes the results into sort, ordering them largest-first (-r reverses, -h handles human-readable sizes).

| head -20 — shows only the top 20 results.

One-line Recipe: Save a List of All Installed Packages

dpkg --get-selections > ~/installed-packages.txt

dpkg --get-selections — lists every package installed on the Pi in a format that can be restored later.

> ~/installed-packages.txt — redirects the output into a file called installed-packages.txt in your home folder. Useful as a backup record before making big changes.

12 — GPIO Quick-Reference

The Pi 5's 40-pin GPIO header lets you connect electronics — LEDs, buttons, sensors, and more. These commands help you work with GPIO from the terminal. All GPIO pins on the Pi 5 operate at 3.3 V logic — never connect a 5 V signal directly to a GPIO pin.

In plain words: GPIO (General-Purpose Input/Output) pins are the row of metal pins along the edge of the Pi board. You can program each one to either read a signal coming in (e.g. from a button) or send a signal out (e.g. to light an LED). They are the Pi's way of talking to the physical world.
Command / Library What it does
pinout Display a colour-coded diagram of the Pi's GPIO pins directly in the terminal — the fastest way to look up which pin is which.
gpio readall Show the current state (high/low, in/out) of every GPIO pin — requires the wiringpi package (sudo apt install wiringpi).
sudo apt install python3-lgpio Install the lgpio library — the recommended GPIO library for Python on Raspberry Pi OS Bookworm.
sudo apt install python3-gpiozero Install the gpiozero library — a beginner-friendly Python GPIO library pre-installed on Raspberry Pi OS.
sudo apt install rpi.gpio Install the classic RPi.GPIO Python library (still works on the Pi 5 via a compatibility layer).
raspi-gpio get Show the current function and level of all GPIO pins.
raspi-gpio set <pin> op Set a GPIO pin to output mode (e.g. raspi-gpio set 17 op).
raspi-gpio set <pin> dh Drive a GPIO pin high (turn it on), e.g. to light an LED.
raspi-gpio set <pin> dl Drive a GPIO pin low (turn it off).
Careful: The Pi 5's GPIO pins use 3.3 V logic and have a maximum current of around 16 mA per pin. Never connect them directly to 5 V, and always use a resistor (typically 330 Ω) in series with an LED to limit the current. Damage to GPIO pins is not covered by warranty.

Key terms

  • Terminal — the text window where you type commands; on Raspberry Pi OS it is the black LXTerminal window.
  • Command — a short text instruction typed at the terminal prompt that makes the Pi do something immediately.
  • Prompt — the text the terminal shows to indicate it is ready for your next command; usually ends with a $ sign.
  • Sudo — stands for "superuser do"; runs the following command with full administrator privileges.
  • Root — the top-level directory of the entire Linux file system, written as /; also the name for the administrator account.
  • Home folder — your personal folder (e.g. /home/pi) where your files and settings live.
  • Permissions — the read/write/execute rules attached to each file that control who can access or run it.
  • Package — a bundle of software (program + supporting files) managed by the apt package manager.
  • Package manager (apt) — the tool that downloads, installs, updates, and removes software packages on Raspberry Pi OS.
  • Service / Daemon — a background program that runs without a window, started automatically at boot (e.g. SSH, a web server).
  • systemctl — the command used to start, stop, enable, and check the status of services.
  • journalctl — the command used to read log messages written by services and the system.
  • Virtual environment (venv) — a private, isolated copy of Python for one project so that installed libraries do not affect the rest of the system.
  • Pipe (|) — a character that connects two commands so the output of the first feeds into the input of the second.
  • Redirect (>) — a character that saves a command's output to a file instead of displaying it on screen.
  • GPIO — General-Purpose Input/Output; the 40 programmable pins on the Pi header used to connect and control electronic components.
  • BCM numbering — the GPIO pin numbering system based on Broadcom's internal chip numbers, used by most Python libraries.
  • IP address — a number (e.g. 192.168.1.42) that identifies your Pi on the local network, used for SSH and web connections.
  • SSH — Secure Shell; a way to open a secure remote terminal session on another computer over a network.
  • Throttling — the Pi automatically slowing down its processor to prevent damage when it overheats or the power supply is too weak.

Chapter summary

  • Use pwd, ls, and cd to find your way around the file system; Tab auto-completes as you type.
  • mkdir, cp, mv, and rm create, copy, move, and delete files — remember that rm is permanent with no undo.
  • sudo grants temporary administrator power; use it only when a command genuinely needs it.
  • Always run sudo apt update before installing or upgrading software; use sudo apt full-upgrade (not just upgrade) on Raspberry Pi OS.
  • On Bookworm, do not run plain pip install into the system Python — use a virtual environment (python3 -m venv) or install via sudo apt install python3-<name>.
  • vcgencmd measure_temp and df -h are your quickest health checks for temperature and disk space.
  • systemctl controls background services; journalctl reads their logs when something goes wrong.
  • Always shut down gracefully with sudo shutdown -h now (or the physical power button) before cutting power to protect the microSD card.
  • The pipe (|), redirect (>), and && symbols let you chain commands together into powerful one-liners.
  • Run pinout to see a colour diagram of the GPIO pins; the Pi 5 uses 3.3 V logic — never connect a 5 V signal directly to a GPIO pin.
