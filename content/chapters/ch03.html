Before you press a single button, it helps to understand what is actually happening inside the little computer sitting on your desk. This chapter builds up a mental picture — using everyday analogies — of the key ideas you will meet again and again: operating systems, RAM, storage, booting, Linux, the terminal, files, users, and a few other concepts that sound technical but are really quite simple once you see them clearly.

What Is an Operating System?

Imagine a large restaurant kitchen. Ingredients sit in the fridge and cupboards. The hobs, ovens, and knives are the tools. But without a head chef who decides which ingredients to fetch, which chef cooks which dish, and how the orders from the dining room are handled, the kitchen would be chaos. The operating system is that head chef — it is the software that manages every piece of your computer's hardware and makes sure all the programs you run get what they need, without treading on each other's toes.

In plain words: An operating system (OS) is the master program that runs invisibly in the background whenever the computer is on. It handles the screen, the keyboard, the memory, the storage, and every other program you open. Without it, the hardware is just expensive metal.

Your Windows 11 laptop runs Microsoft Windows as its operating system. Your Raspberry Pi 5 runs Raspberry Pi OS — a version of Linux specially designed for the Pi. It handles everything the same way Windows does, but it looks different and behaves slightly differently in places.

Note: Raspberry Pi OS is free to download and free to use — forever. You do not need a licence key or a subscription.

Hardware Versus Software

These two words are used constantly, so it is worth being crystal clear about them before going any further.

In plain words: Hardware is anything you can physically touch — the circuit board, the RAM chips, the microSD card, the case, the cables. Software is the set of instructions stored on the hardware that tells it what to do — the operating system, apps, games, and any programs you write yourself.

A useful analogy: hardware is the DVD player; software is the film on the disc. The player cannot do anything interesting without a disc, and a disc without a player is just a shiny circle. They need each other.

RAM Versus Storage — A Crucial Distinction

People sometimes confuse RAM and storage because both are measured in gigabytes and both sound like "memory". They serve completely different purposes.

RAM — Your Desk

In plain words: RAM (Random Access Memory) is your computer's working space — like the surface of a desk. When you open a program, the computer loads it from storage onto the desk so it can work with it quickly. The bigger the desk, the more things you can have open at once without things slowing down.

Your Raspberry Pi 5 has 16 GB of RAM. That is an unusually generous amount for a Pi — it means you can run a web browser, a code editor, a music player, and several other programs all at the same time without the computer struggling.

Here is the critical thing about RAM: it is wiped clean every time you turn the power off. Whatever was on the desk gets swept onto the floor the moment the lights go out. That is why you must save your work to a file before switching off.

Storage — Your Filing Cabinet

In plain words: Storage is where files live permanently — like a filing cabinet. Unlike RAM, storage keeps its contents when the power is off. On a typical laptop, the filing cabinet is an internal hard drive or SSD. On your Raspberry Pi 5, the filing cabinet is the microSD card.

The microSD card in your iRasptek kit (64, 128, or 256 GB depending on which version you have) plays the role that a hard drive plays in a laptop. Raspberry Pi OS itself is installed on it, and every file you create, every program you install, and every setting you change is stored there.

Careful: MicroSD cards are tougher than they look, but they can still be damaged by being pulled out while the Pi is running. Always shut down properly before removing the card. You will learn how to shut down safely in Chapter 4.

What Does "64-bit" Mean?

You will notice that Raspberry Pi OS is described as a 64-bit operating system. This comes up often enough that it is worth a brief explanation.

In plain words: Bits are the smallest unit of information a computer works with — think of them as on/off switches. A 64-bit processor can handle 64 switches at a time; an older 32-bit processor handled only 32 at a time. More bits at once means the processor can address far more memory, work with bigger numbers in one step, and generally run modern software more efficiently.

Your Pi 5 has a 64-bit ARM processor, and the version of Raspberry Pi OS on your card is the 64-bit edition. This is the recommended version for all Pi 5 boards. In practice, you will rarely need to think about this — just know that if a website ever offers you a choice between a 32-bit and 64-bit download for Linux, always pick 64-bit for your Pi 5.

What Does "Booting" Mean?

In plain words: Booting (or "starting up") is the process the computer goes through from the moment you switch it on until it is ready for you to use. The word comes from the old phrase "pulling yourself up by your bootstraps" — the computer is loading the instructions it needs to load more instructions, step by step, until the full operating system is running.

Here is what happens when you plug in your Raspberry Pi 5:

  1. Power flows to the board. A tiny built-in chip (the bootloader) wakes up.
  2. The bootloader looks at the microSD card and finds Raspberry Pi OS.
  3. It loads the OS into RAM and hands over control.
  4. Raspberry Pi OS starts all its background services (Wi-Fi, screen, keyboard, and so on).
  5. The desktop appears and you can start working.

On the Pi 5, this process takes roughly 20–30 seconds from power-on to a usable desktop. You will see a rainbow square briefly, then a bouncing Raspberry Pi logo, and then the desktop.

Tip: The rainbow square is completely normal — it just means the GPU (graphics chip) has started. It disappears after a second or two.

Two Ways to Talk to the Computer

There are two fundamentally different ways of giving your Raspberry Pi instructions, and you will use both of them throughout this book.

The Graphical Way (Desktop)

This is the one that looks like Windows. You see a wallpaper, icons, a taskbar, windows that open and close. You use a mouse to click on things. Everything you want to do has a visual representation — a picture of a file, a button to press, a menu to open.

Raspberry Pi OS's graphical desktop is called PIXEL (which stands for "Pi Improved Xwindows Environment, Lightweight" — but you will never need to remember that). It looks clean and simple, with the Raspberry Pi logo in the top-left corner as the main menu button.

Note: If you have used Windows or a Mac before, the desktop will feel familiar within a few minutes. The icons and menus work in the same way, even if they are in slightly different places.

The Terminal Way (Typing Commands)

In plain words: The terminal (also called the command line, command prompt, or shell) is a text window where you type instructions and the computer types back its response. There are no icons or buttons — just text. It looks old-fashioned, but it is extraordinarily powerful and is the method that most Pi projects and guides (including much of this book) rely on.

You open the terminal on Raspberry Pi OS by clicking the black rectangle icon on the taskbar, or by going to the Raspberry Pi menu → Accessories → Terminal.

When the terminal opens, you will see something like this:

pi@raspberrypi:~ $
This line is called the prompt — the terminal's way of saying "I am ready, what would you like me to do?" It tells you four things at a glance: pi is your username (the name of the account you are logged in as); raspberrypi is the computer's name (its "hostname" on the network); ~ means you are currently in your home folder (the tilde character is a shortcut for your personal folder); and $ is the signal that you can now type a command. If your username is something other than pi — which is possible if the card was set up with a different name — you will see that name instead.

You type a command and press Enter. The computer carries it out and shows the result. For example:

date
The command date asks the computer to display the current date and time. After pressing Enter, the terminal will print something like Fri 19 Jun 2026 10:30:05 BST and then show the prompt again, ready for the next command. This is harmless — a good first command to try the moment your terminal is open.

Neither the graphical way nor the terminal way is "better" — they are two tools for two slightly different jobs. The desktop is convenient for browsing, opening documents, and adjusting settings. The terminal is faster and more precise for installing software, configuring the Pi, and running projects. This book teaches you both, so you will always choose the right tool for the task.

What Is Linux?

In plain words: Linux is a family of operating systems. Just as there are many brands of car (all with four wheels, a steering wheel, and an engine), there are many versions of Linux — they share the same core but look and behave a little differently. Ubuntu, Debian, Fedora, and Raspberry Pi OS are all members of the Linux family.

Linux was created in 1991 by a Finnish student named Linus Torvalds. He made the source code — the recipe for how it works — publicly available so that anyone could read it, improve it, and share their improvements. Decades later, this collaborative effort has produced one of the most reliable, secure, and widely used operating systems in the world. Linux runs most of the world's web servers, every Android phone, and almost every supercomputer.

In plain words: Open source means the recipe (source code) is published for anyone to read, use, modify, and share. Free software in the Linux world usually means free as in freedom — you have the right to study and change it — as well as free as in no cost. Raspberry Pi OS is both.

Raspberry Pi OS is built on top of Debian, one of the oldest and most stable Linux distributions. The version currently installed on your Pi is called Bookworm (Debian 12, released 2023). Debian names its releases after characters from the film Toy Story.

Tip: Because Linux is open source, there is a huge community of people who have solved the same problems you will encounter. Searching "Raspberry Pi [your question] Bookworm" on the web almost always finds a working answer.

What Is ARM? And Why Does It Occasionally Matter?

Your Windows 11 laptop almost certainly uses a processor made by Intel or AMD. Your Raspberry Pi 5 uses a completely different type of processor designed around something called the ARM architecture.

In plain words: A processor's architecture is the language it speaks internally — the set of instructions it understands. Just as a French speaker and a Japanese speaker cannot understand each other without a translator, a program built for Intel/AMD will not run directly on an ARM chip. The program must be compiled (built) specifically for the architecture it will run on.

ARM stands for "Advanced RISC Machine" — but you never need to remember that. What matters is that ARM chips are designed to be extremely energy-efficient, which is why they are used in phones, tablets, and single-board computers like the Pi. The Pi 5's processor (Broadcom BCM2712, with four Arm Cortex-A76 cores running at 2.4 GHz) is powerful enough to run a full desktop operating system while drawing very little power.

Feature Intel / AMD (typical Windows PC) ARM (Raspberry Pi 5)
Architecture x86-64 AArch64 (64-bit ARM)
Power use 65–125 W (desktop) / 15–45 W (laptop) 5–15 W (typical Pi 5 use)
Typical use Desktop PCs, laptops Phones, tablets, embedded projects, Pi
Software Windows .exe files (built for x86-64) ARM binaries (built for AArch64)

In practice, for everyday tasks on the Pi — browsing the web, writing documents, running Python programs — you will never notice the difference. Raspberry Pi OS and its software repository already contain ARM-compiled versions of everything you are likely to need. The only time it matters is if you try to download a program as a Windows .exe file or find a Linux program that was only compiled for Intel — in which case it simply will not run. The solution is always to install software through Raspberry Pi OS's built-in package manager (covered in Chapter 6), which automatically gives you the right version for your chip.

Files, Folders, and Paths

You are probably familiar with files and folders from Windows. The concept is identical on Linux, but there are a few important differences in how they are organised and written about.

Files and Folders

A file is a named collection of data stored on the microSD card — a document, a photo, a program, a piece of music. A folder (also called a directory on Linux) is a container that holds files and other folders, letting you organise things into a hierarchy, just like real folders in a real filing cabinet.

The Root and Your Home Folder

On Windows, each storage drive gets a letter: C:\, D:\, and so on. Linux works differently. There is one single tree starting from a folder called the root, written simply as /. Everything — all your files, all installed programs, all the operating system itself — hangs off this single root.

In plain words: On Linux, / (a single forward slash) is the very top of the file system — the trunk of a tree from which all other folders branch. It is called the root directory.

Inside the root, there are several important folders. The one you will use most is your home folder: /home/pi (or /home/yourname if you chose a different username during setup). This is your personal space — think of it as My Documents on Windows. When you open the terminal, you start here automatically. The tilde symbol ~ is a shortcut that always means your home folder, so ~/Documents is the same as /home/pi/Documents.

Note: On Raspberry Pi OS Bookworm, if the microSD card was pre-installed for you (as in most iRasptek kits), your username and home folder may already be set to pi. If you set up the card yourself using Raspberry Pi Imager, you chose your own username. Either way, ~ always points to the right place, whatever your username is.

Paths

In plain words: A path is the full address of a file or folder — the set of directions that tells the computer exactly where to find something, starting from the root and working down through the folder tree.

Paths on Linux use forward slashes /, not the backslashes \ you may be used to from Windows. For example:

  • /home/pi/Documents/hello.txt — a file called hello.txt inside the Documents folder inside your home folder.
  • /usr/bin/python3 — the Python 3 program, stored in the system's program folder.
  • ~/Pictures/holiday.jpg — a photo in your Pictures folder (using the ~ shortcut).
Note: Linux file names are case-sensitive. A file named Hello.txt and a file named hello.txt are treated as two different files. Windows ignores case; Linux does not. This trips up many beginners — if a command complains it cannot find a file, check the capitalisation first.

A Quick Look at the Folder Tree

Here are the folders you are most likely to encounter. You do not need to memorise them all — just keep this table as a reference.

Folder What it contains
/ The root — the very top of the file system
/home/pi Your personal files (documents, pictures, projects). Replace pi with your own username if different.
/home/pi/Desktop Files and shortcuts that appear on the desktop
/etc Configuration files for the whole system
/usr/bin Programs installed for all users
/tmp Temporary files — wiped on every reboot
/boot/firmware Files the Pi needs to start up (on Bookworm the boot files live in this subfolder — not in /boot directly)
/media/pi Where USB drives and other external storage appear when you plug them in
/var/log System log files — useful when something goes wrong
Tip: You can explore these folders visually using the file manager on the desktop (the folder icon on the taskbar), just as you would in Windows Explorer. There is no need to use the terminal to browse files unless you prefer to.

Users, the Administrator, and sudo

Linux was designed from the very beginning to be used by many people at once (on a shared computer or server). Even though you are the only person using your Pi, Linux still thinks in terms of users.

Your User Account

When Raspberry Pi OS first starts on a pre-installed card, it either sets up a default account named pi, or — if you used Raspberry Pi Imager to prepare the card yourself — the username you chose during setup. You are logged in as that account whenever you are using the desktop or the terminal.

Your user account can do almost everything you need day-to-day: create files, browse the web, run programs, write code. But certain things — installing software system-wide, changing core settings, or modifying files outside your home folder — require special permission.

The Administrator (Root)

In plain words: On Linux, the all-powerful administrator account is called root. Root can do literally anything to the system — delete every file, break the operating system, install anything. Because of this power, you almost never log in directly as root. Instead, you use a command called sudo to temporarily borrow root's powers for a single command.
In plain words: sudo stands for "superuser do". You put it in front of a command to run that one command with administrator privileges. Think of it as showing your ID at a secure door — you do not move into the secure area permanently, you just get access for that one moment.

You will see sudo constantly in Pi guides. Here is an example — updating the list of available software:

sudo apt update
Line by line: sudo — run the following command with administrator (root) powers; apt — this is the package manager, the built-in program that installs and updates software on Raspberry Pi OS; update — tells apt to download the latest list of available software packages from the internet, so your Pi knows what is available and what version is current. Without sudo, this command would be refused because only an administrator can modify system-wide software lists. You will run this command frequently throughout the book.
Careful: Because sudo gives you full administrator power, a typo in a sudo command can cause real damage. Always double-check a command before pressing Enter when sudo is involved. Never copy a sudo command from an unknown website without understanding what it does.

When you first use sudo in a terminal session, Raspberry Pi OS will ask for your password. Type it and press Enter. (The characters will not appear on screen as you type — this is intentional and is a security feature, not a bug.)

Note: Your everyday account (for example, pi) is a member of a group called sudo, which is what grants it permission to use the sudo command at all. You are already in this group on any standard Raspberry Pi OS setup — you do not need to do anything to enable it.

Users and Groups — A Brief Mention

Linux also organises users into groups. Groups are used to grant shared permissions — for example, the gpio group grants access to the Pi's physical pins, and the audio group grants access to audio devices. Your account is already added to all the groups it needs by default, so this is mostly invisible to you. You may occasionally encounter it in more advanced projects, and at that point the project's instructions will tell you exactly what to do.

Open Source and "Free" Software — What These Actually Mean

You will see the words "free" and "open source" everywhere in the Raspberry Pi community. They are worth understanding properly because they affect how you can use, share, and build on the software.

Free as in Freedom

In the computing world, "free software" does not just mean zero cost (though it usually is zero cost). It means you have four essential freedoms:

  1. Freedom to use the software for any purpose.
  2. Freedom to study how it works (by reading the source code).
  3. Freedom to share copies with others.
  4. Freedom to improve it and share your improvements.

Raspberry Pi OS, Linux, Python, the LibreOffice suite, the Firefox web browser, and thousands of other programs you will use on the Pi are all free in this sense. Nobody can take them away from you, charge you a subscription, or prevent you from looking under the bonnet.

Open Source

In plain words: Source code is the human-readable set of instructions that a programmer writes. Open source means that source code is published publicly, so anyone can read, learn from, verify, and improve it. The opposite is proprietary or closed-source software, where the recipe is a trade secret (like Windows or macOS).

Open source matters for practical reasons beyond philosophy. Because thousands of developers worldwide can inspect the code, bugs and security vulnerabilities are spotted and fixed faster. No single company can abandon the project and leave you stranded. And the huge library of open-source software available for Linux means there is almost always a free, capable alternative to any commercial program you might need.

Tip: The Raspberry Pi Foundation itself publishes most of its tools as open source. If you ever become curious about how something works under the hood, the code is there for you to read.

Putting It All Together — A Layers Picture

Keep this picture in mind as you work through the rest of this book. When something goes wrong, you can often work out which layer the problem is in — is the hardware not responding? Is the OS confused? Is the app misbehaving? — and that points you towards the right solution.

Key terms

  • Operating system (OS) — the master program that manages all of a computer's hardware and software.
  • Raspberry Pi OS — the official Linux-based operating system for the Raspberry Pi, based on Debian Bookworm.
  • Hardware — the physical components of a computer (circuit board, chips, cables, case).
  • Software — programs and data; the instructions that hardware follows.
  • RAM — fast, temporary working memory; wiped when power is off.
  • Storage — permanent memory (the microSD card on the Pi) that survives power-off.
  • 64-bit — a processor (and OS) that handles 64 data switches at once; gives access to more memory and runs modern software more efficiently than older 32-bit systems. The Pi 5 and Raspberry Pi OS Bookworm are both 64-bit.
  • Booting — the start-up process from power-on to a ready desktop.
  • Terminal / command line — a text window where you type commands instead of clicking.
  • Prompt — the text the terminal shows (e.g. pi@raspberrypi:~ $) to indicate it is ready for a command.
  • PIXEL — the name of the graphical desktop environment used by Raspberry Pi OS.
  • Linux — a family of open-source operating systems; Raspberry Pi OS is a member.
  • Debian Bookworm — the specific version of Linux that Raspberry Pi OS is based on (version 12, released 2023).
  • ARM — the processor architecture used by the Raspberry Pi 5; different from the x86-64 architecture in most Windows PCs.
  • Architecture — the internal instruction language of a processor; software must be built for the right architecture to run.
  • Root directory (/) — the very top of the Linux file system, from which all folders branch.
  • Home folder (~) — your personal folder on Linux, typically /home/pi (or /home/yourname if you chose a different username).
  • Path — the full address of a file or folder (e.g. /home/pi/Documents/hello.txt).
  • Case-sensitive — Linux treats Hello.txt and hello.txt as different files; capitalisation matters.
  • root (user) — the all-powerful administrator account on Linux.
  • sudo — a command prefix that runs a single command with administrator (root) privileges.
  • apt — the package manager on Raspberry Pi OS; the built-in tool for installing and updating software.
  • Open source — software whose source code is published for anyone to read, use, and improve.
  • Source code — the human-readable instructions a programmer writes to create a program.
